## 一、设计目标

围绕"长文沉浸阅读"这一核心场景，优化五个方面：

| # | 目标 | 现状问题 |
|---|------|----------|
| 1 | 排版格式优化 | 正文 `#111827` 过黑，纯白背景刺眼，段间距 1em 偏紧 |
| 2 | 配色优化 | 浅色模式缺纸张感；深色模式文字 `#e2e8f0` 对比过强 |
| 3 | 沉浸式阅读模式 | 顶栏/侧栏/翻页常驻，无聚焦模式 |
| 4 | 断点续看 | 只记忆章节（`book-lastchapter`），不记忆滚动位置 |
| 5 | 左侧目录栏 | active 状态整块深底白字过重，字号偏大，无当前章指示条 |

一句话概括：**纸感配色 + 沉浸聚焦 + 精细目录 + 无缝续读**。

## 二、配色系统优化

### 2.1 设计原则

引入 **CSS 变量统一管理颜色**，浅/深/沉浸三态只切换变量值，避免散落的十六进制值。核心思路：**浅色如纸、深色护眼、金色点缀不变**。

### 2.2 颜色变量定义

```css
:root {
  /* 品牌色（不变） */
  --navy: #1e3a5f;
  --navy-deep: #15293f;
  --gold: #b8860b;
  --gold-light: #d4a843;

  /* 浅色：暖纸白 */
  --bg-page: #faf9f6;        /* 页面背景：暖纸白，替代纯白 */
  --bg-surface: #fffdf9;     /* 卡片/阅读底：略亮于页面 */
  --bg-inset: #f4f2ec;       /* 引用/hover 底：米灰 */
  --text-body: #2f2a24;      /* 正文：暖墨色，替代 #111827 */
  --text-secondary: #6b6459; /* 次要文字：暖灰 */
  --text-faint: #a39c8f;     /* 辅助文字 */
  --border-subtle: #e8e4da;  /* 细边框 */

  /* 深色：护眼暖黑 */
  --bg-page-dark: #12161d;
  --bg-surface-dark: #1a2029;
  --bg-inset-dark: #202834;
  --text-body-dark: #c9d1dc;   /* 替代 #e2e8f0，降低刺眼感 */
  --text-secondary-dark: #8a93a1;
  --border-subtle-dark: #2a323d;
}
```

### 2.3 三态配色表

| 角色 | 浅色 | 深色 | 沉浸（跟随主题） |
|------|------|------|------------------|
| 页面背景 | `#faf9f6` 暖纸白 | `#12161d` 暖黑 | 同主题，但阅读区外背景降饱和 |
| 正文 | `#2f2a24` 暖墨 | `#c9d1dc` 柔灰 | 同主题 |
| 强调 | gold `#b8860b` | gold-light `#d4a843` | 不变 |
| 引用底 | `#f4f2ec` 米灰 | `#202834` | 同主题 |

**要点**：
- 浅色正文从 `#111827`（冷黑）→ `#2f2a24`（暖墨），长时间阅读不"发硬"
- 深色正文从 `#e2e8f0` → `#c9d1dc`，对比度从 AAA 降至 AA+，夜读不刺眼
- 表头 navy 底、金色装饰线全部保留，品牌气质不变

## 三、排版系统优化

### 3.1 正文参数

| 参数 | 现状 | 优化后 | 理由 |
|------|------|--------|------|
| 字号 | 18px（16-22 可调） | 18px（16-22 可调，步进 1px） | 保持 |
| 行高 | 1.85 | **1.9** | 中文长文更松弛的呼吸感 |
| 段间距 | 1em | **1.15em** | 段落分隔更清晰 |
| 对齐 | justify + inter-ideograph | 保持 | 中文两端对齐最佳实践 |
| 阅读宽度 | 720px | 标准 720px / **沉浸 680px** | 沉浸时视线更聚焦 |
| 字重 | 400 | 400（strong 600） | 中文衬线加粗 700 过重，600 更雅 |

### 3.2 标题层级

| 层级 | 现状 | 优化后 |
|------|------|--------|
| h1（章题） | 1.75em，金色下划线 | **2em**，下划线改 3px 渐变（gold→transparent），段前 2.2em |
| h2（节题） | 1.3em，左金条 4px | **1.35em**，金条改 3px + 半透明，段前 2em |
| h3 | 1.1em | **1.15em**，颜色降一级 |
| h4+ | 1em | 保持，颜色同 h3 但字重 500 |

### 3.3 元素细节

| 元素 | 优化 |
|------|------|
| 引用块 | 背景米灰 `--bg-inset`，左金条 3px，圆角 0 10px 10px 0，内边距 1.1em 1.4em |
| 表格 | 表头 navy 底白字保留；行 hover 高亮 `rgba(184,134,11,.04)`；圆角外框 + 细边框 |
| 分隔线 hr | 改为居中短金线（宽 60px），替代通栏线，更书卷气 |
| 列表 | li 行距 1.75，marker 颜色随正文 |
| code | 底色 `--bg-inset`，色 gold-dark，圆角 4px |

### 3.4 移动端

- 字号默认 17px，行高 1.85
- 阅读区内边距 24px 18px → 20px 16px
- 表格保持横向滚动

## 四、沉浸式阅读模式

### 4.1 模式定义

沉浸模式 = **一键隐藏所有界面元素，只留正文与进度条**。

### 4.2 状态与触发

| 项 | 设计 |
|----|------|
| 状态 | `immersive: false`（Alpine 状态，localStorage 持久化 `book-immersive`） |
| 入口 | 顶栏新增图标按钮（书本/聚焦图标），tooltip "沉浸阅读" |
| 快捷键 | `I` 进入/退出；`Esc` 退出 |
| 持久化 | 刷新后保持，仅在阅读视图生效 |

### 4.3 视觉效果

| 元素 | 沉浸模式下 |
|------|-----------|
| 顶栏 | `translateY(-100%)` 滑出隐藏 |
| 侧边目录（桌面） | `translateX(-100%)` 滑出，阅读区占满居中 |
| 翻页按钮 | 透明度 0.15，hover 恢复 1 |
| 进度条 | 保留，高度 3px → 2px |
| 阅读区宽度 | 720px → 680px |
| 页面背景 | 应用沉浸配色（阅读区外背景降饱和、去卡片边框感） |

### 4.4 唤出顶栏（沉浸中）

顶部 48px 高的**隐形触发区**（`.immersive-hover-zone`），鼠标移入时顶栏滑出，移出后 1.5 秒自动收回：

```
鼠标移到屏幕顶部 ──→ hover-zone 触发 ──→ 顶栏滑入 ──→ 移开 1.5s 后滑出
```

实现：CSS `:hover` + `transition-delay: 1.5s` 在移出侧，零 JS 计时器。

### 4.5 移动端

- 沉浸模式隐藏顶栏，保留底部悬浮"目录"圆钮（点击唤出抽屉）
- 顶部触发区同样生效（触摸顶部边缘唤出顶栏）

## 五、断点续看（滚动位置记忆）

### 5.1 数据结构

| Key | 值 | 说明 |
|-----|-----|------|
| `book-lastchapter` | 章节 id | 已有，保持 |
| `book-pos-{chapterId}` | scrollY 数值 | **新增**：每章独立滚动位置 |
| `book-immersive` | '1' / '0' | 沉浸模式状态 |

### 5.2 行为设计

```
阅读中滚动 ──(防抖 400ms)──→ 保存 book-pos-{当前章}
进入章节 ──┬─ 目录/首页/hash 直达进入 → 恢复到记忆位置 + Toast 提示
           └─ 上一章/下一章翻页进入 → 从顶部开始（阅读新章的自然期望）
```

| 规则 | 说明 |
|------|------|
| 保存时机 | `onScroll` 内防抖 400ms 写 localStorage，仅阅读视图 |
| 恢复时机 | 章节渲染完成（fetch 或缓存命中）后 `$nextTick` 中恢复 |
| 越界保护 | 恢复位置 = `min(记忆值, scrollHeight - clientHeight)`，内容更新后不悬空 |
| Toast 提示 | 恢复成功时底部显示"已回到上次阅读位置"，2.5 秒淡出 |
| 清理策略 | 不清理（40 章最多 40 条 key，体量可忽略） |

### 5.3 Toast 组件

```html
<div class="toast" x-show="toast" x-text="toast"></div>
```

- 固定底部居中，深底白字圆角，`transition` 淡入淡出
- 方法 `showToast(msg, 2500)`，通用设计后续可复用（如"主题已切换"）

## 六、左侧目录栏重设计

### 6.1 布局参数

| 参数 | 现状 | 优化后 |
|------|------|--------|
| 宽度 | 256px（w-64） | **264px** |
| 对齐 | 左对齐 | **左对齐（明确 `text-align: left`）** |
| 章节字号 | 14px（.875rem） | **13.5px（.84rem）**，行高 1.5 |
| 章节标题截断 | 单行 | **最多两行**（`-webkit-line-clamp: 2`），完整可 hover 展开 title |
| 内边距 | .4rem .75rem | .45rem .9rem（序号与标题间距加大） |
| 项间距 | 紧凑 | 2px，阅读不拥挤 |

### 6.2 层级样式

**篇标题（分组头）**：
- 11px / 字重 700 / 金色 `--gold` / `letter-spacing: .06em`
- 形如 `第一部分 · 市场环境与机会调研`，上下留白 14px / 6px
- 下方不加线，靠留白分组

**章节项**：
```
┌──────────────────────────────┐
│ 01  回国决策总论与 2026 时代背景 │   ← 序号 11px 等宽金色 60%，标题 13.5px 左对齐
└──────────────────────────────┘
```

| 状态 | 样式 |
|------|------|
| 默认 | 文字 `--text-secondary`，透明背景 |
| hover | 背景 `--bg-inset`，文字 `--navy`，过渡 .15s |
| **当前章** | 左侧 **3px 金色竖条** + 背景 `rgba(184,134,11,.08)` + 文字 navy 加粗；深色下竖条 gold-light、背景 `rgba(212,168,67,.12)` |

**废弃旧方案**：整块 navy 底白字（`background: #1e3a5f; color: #fff`）视觉过重，且与金色品牌色脱节。

### 6.3 智能定位

打开章节时，侧栏自动 `scrollIntoView({ block: 'nearest' })` 将当前章滚动至可视区，长列表不迷路。

### 6.4 滚动条

- 宽 6px，thumb 圆角 `--border-subtle`，hover 加深
- 轨道透明，与页面融为一体

## 七、交互细节

| 项 | 设计 |
|----|------|
| 键盘 | `←/→` 翻章（已有）；`I` 沉浸；`Esc` 退出沉浸/关闭抽屉；`+/-` 字号 |
| 顶栏 | 普通模式常驻毛玻璃（`backdrop-blur` 保留）；沉浸模式滑出 |
| 翻页卡片 | 改为双栏卡片：章号小字 + 标题，hover 金色描边上浮 1px |
| 阅读区入场 | `fade-enter` 保留 0.3s，另加 8px 上移（`translateY(8px)→0`），更轻盈 |
| 进度条 | 渐变金保持，`will-change: width` 避免重排抖动 |
| 平滑滚动 | `scroll-behavior: smooth` 保留；恢复位置时改 `auto` 瞬时定位（避免长距离滚动动画） |

## 九、验收标准

| # | 验收项 | 通过标准 |
|---|--------|----------|
| 1 | 排版 | 行高 1.9、段距 1.15em、正文暖墨色，深浅两态均可舒适长读 |
| 2 | 配色 | 浅色纸感 / 深色护眼，全部颜色出自 CSS 变量 |
| 3 | 沉浸模式 | 按钮或 `I` 进入；顶栏/侧栏隐藏、阅读区 680px；顶部悬停唤出顶栏；`Esc` 退出；刷新保持 |
| 4 | 断点续看 | 滚动后刷新/重进同章恢复位置并 toast 提示；翻页进入新章从头开始；越界不悬空 |
| 5 | 目录栏 | 左对齐、13.5px 两行截断、当前章金色竖条指示、打开章节自动定位 |
| 6 | 兼容 | 移动端沉浸可用（底部目录圆钮）、三档响应式不破版 |
| 7 | 回归 | 首页、主题切换、字号、进度条、缓存/预加载、hash 路由全部不受影响 |

## 十、不做范围

- 不做段落级聚焦（当前段高亮）——视觉干扰大于收益
- 不做自动翻页/朗读——超出本书阅读器定位
- 不做全文搜索——维持既有排除决策
- 不改首页七区块视觉——本次只优化阅读体验
