## 6. 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| CDN 不可达（网络问题） | 中 | 样式降级 | 已有 fallback 字体；本地测试时若 CDN 不通可下载到本地引用 |
| marked 解析大表格性能 | 低 | 个别章节渲染慢 | 40 章最大 15KB，性能无忧 |
| Google Fonts 加载慢 | 中 | 首屏字体闪烁 | fallback 字体兜底，可加 `font-display: swap` |
| fetch 跨域（file:// 打开） | 中 | 章节加载失败 | 文档已强调需 HTTP 服务器，T9 用 `python -m http.server` |
| Tailwind Play CDN 生产警告 | 低 | 控制台 warning | 本书为静态内容站，可接受；生产可后续切 Tailwind CLI |
