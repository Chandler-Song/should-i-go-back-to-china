# 《要不要回国？》 Should I Go Back to China?

> 面向在海外（尤其硅谷）工作的资深工程师 / 技术管理者，提供一套从信息调研到落地执行的回国方法论。
> 全书 **40 章 · 约 14 万字 · 9 大板块**，覆盖市场、薪酬、城市、家庭、心理、时机、案例、时代挑战、实操。

**在线阅读** → https://chandler-song.github.io/should-i-go-back-to-china/

## 书籍介绍

### 这本书讲什么

大模型时代正在重塑全球软件工程师的劳动市场；与此同时，中美科技脱钩深化、国内 AI 与芯片自主可控加速、海归人才政策周期性收紧又放开——这是过去二十年最复杂的一次「回国决策窗口期」。

本书不灌鸡汤、不给标准答案，而是提供一套**可执行的调研方法 + 决策框架 + 实操清单**，帮你用 3–6 个月完成从「想回国」到「签 offer 落地」的全流程。

### 适读对象

- 在海外工作 **5–15 年**、技术/管线上有积累的工程师、管理者；
- 年龄 **30–45**、正在认真评估回国选项的读者（已婚或单身均可）；
- 想以**硅谷工程师视角 + 数据 + 反例 + 心理学模型**做理性决策的人。

> **不是**留学中介话术、猎头软文或情绪共鸣散文。
