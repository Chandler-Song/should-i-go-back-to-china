## 为什么写这本书

大模型时代正在重塑全球软件工程师的劳动市场。与此同时，中美科技脱钩深化、国内 AI 与芯片自主可控加速、海归人才政策周期性收紧又放开——这是过去二十年最复杂的一次"回国决策窗口期"。本书不灌鸡汤，不给标准答案，而是提供一套**可执行的调研方法 + 决策框架 + 实操清单**，让你在 3-6 个月内完成从"想回国"到"签 offer 落地"的全流程。

## 本书定位

- **不是**：留学中介话术、猎头软文、情绪共鸣散文。
- **是**：硅谷资深工程师视角的、带数据、带反例、带心理学模型的决策手册。
- **读者画像**：在海外工作 5-15 年，技术/管线上有积累，年龄 30-45，已婚或单身均可能，正在认真评估回国选项的人。

## 使用说明

1. 本书各章独立成篇，可跳读。但第 01、25、29 三章构成决策骨架，建议先读。
2. 数据为 2024-2026 年公开信息综合判断，**薪酬、政策、房价变动快，落地前务必用第 21 章方法做一次信息刷新**。
3. 本书刻意保留"反例"与"失败案例"，因为回国决策中**知道别人怎么栽的，比知道别人怎么成的更重要**。
4. 心理学部分（第 25-28 章）是本书区别于市面上所有回国攻略的核心，请认真对待——大多数回国决策的失败不是信息问题，是心理问题。
