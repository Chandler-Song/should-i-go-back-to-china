# 第 17 章　宜居排名与个人化加权

> 宜居不是看排行榜，是看"你的"宜居。本章给一套个人化宜居加权模型，让你算出"对你"最宜居的城市。

---

## 17.1　宜居的十个维度

本书把宜居拆成十个维度：

1. **气候**：温度 / 湿度 / 空气 / 四季。
2. **自然环境**：山水 / 绿化 / 公园 / 海。
3. **通勤**：平均通勤时间 / 地铁覆盖 / 拥堵。
4. **医疗**：医院质量 / 挂号难易 / 看病等待。
5. **教育**：公立质量 / 国际学校 / 内卷度。
6. **文化娱乐**：博物馆 / 演出 / 餐饮 / 夜生活。
7. **安全**：治安 / 食品 / 交通安全。
8. **生活便利**：购物 / 服务 / 外卖 / 快递。
9. **节奏**：工作节奏 / 生活节奏 / 压力。
10. **社会包容**：对外地人 / 海归 / 多元的包容度。

## 17.3　个人化宜居加权模型

```
你的宜居分 = Σ (维度分 × 你的权重)
权重和 = 100%
```

**示例一**：单身工程师，重视气候 + 文娱 + 包容：

- 气候 20% / 自然 10% / 通勤 10% / 医疗 5% / 教育 5% / 文娱 20% / 安全 5% / 便利 10% / 节奏 5% / 包容 10%
- 北京：2×.2+3×.1+2×.1+5×.05+5×.05+5×.2+4×.05+5×.1+1×.05+4×.1 = 3.5
- 上海：3×.2+3×.1+3×.1+5×.05+4×.05+5×.2+4×.05+5×.1+2×.05+5×.1 = 3.85
- 杭州：4×.2+5×.1+3×.1+4×.05+4×.05+4×.2+4×.05+5×.1+3×.05+4×.1 = 4.0
- **结论**：杭州 > 上海 > 北京。

**示例二**：有子女家庭，重视教育 + 医疗 + 节奏：

- 气候 10% / 自然 5% / 通勤 10% / 医疗 15% / 教育 25% / 文娱 5% / 安全 10% / 便利 5% / 节奏 10% / 包容 5%
- 北京：2×.1+3×.05+2×.1+5×.15+5×.25+5×.05+4×.1+5×.05+1×.1+4×.05 = 3.6
- 上海：3×.1+3×.05+3×.1+5×.15+4×.25+5×.05+4×.1+5×.05+2×.1+5×.05 = 3.75
- 成都：4×.1+4×.05+3×.1+4×.15+4×.25+4×.05+4×.1+5×.05+4×.1+4×.05 = 3.9
- **结论**：成都 > 上海 > 北京。

**关键**：**你的权重决定结果**，没有 universally 最宜居的城市。

## 17.4　不同画像的宜居推荐

### 画像一：单身工程师 / 30 出头 / 重视机会 + 文娱

- **推荐**：北京（机会最多）、上海（文娱 + 国际化）、杭州（阿里 + 宜居）。
- **权重**：产业 + 文娱 + 包容高，节奏 / 教育低。

### 画像二：已婚无子女 / 重视宜居 + 配偶就业

- **推荐**：上海（配偶 + 国际化）、杭州（宜居 + 阿里）、苏州（宜居 + 外企）。
- **权重**：配偶 + 宜居 + 包容高，节奏中。

### 画像三：有子女 / 重视教育 + 节奏

- **推荐**：成都（教育 + 慢）、杭州（教育 + 宜居）、上海（教育 + 国际化）。
- **权重**：教育 + 节奏 + 医疗高，产业中。

### 画像四：40+ / 重视慢节奏 + 健康

- **推荐**：成都（慢 + 宜居）、苏州（慢 + 宜居）、南京（慢 + 教育）。
- **权重**：节奏 + 气候 + 医疗高，产业低。

### 画像五：硬科技 / 重视产业 + 政策

- **推荐**：合肥（硬科技 + 政策）、西安（航天芯片）、武汉（存储）。
- **权重**：产业 + 政策高，文娱低。

## 17.5　宜居的"长期变化"判断

宜居不只看现在，看 5-10 年变化：

- **北京**：机会持续但内卷 + 气候短期难改善，长期宜居度中。
- **上海**：国际化 + 宜居持续，长期宜居度高。
- **深圳**：年轻 + 房价回调，长期宜居度中高。
- **广州**：宜居 + 低成本持续，长期宜居度高。
- **杭州 / 成都**：宜居 + 产业承接，长期宜居度最高之一。
- **武汉 / 西安 / 合肥**：硬科技 + 政策，长期宜居度中但上升。
- **南京 / 苏州**：宜居 + 慢，长期宜居度高。

**长期判断**：**杭州 / 成都 / 苏州 / 上海 / 广州**是长期宜居度最高的城市。

## 17.6　宜居的"家庭同步"问题

宜居不只看你自己，看家庭：

- **配偶宜居**：配偶对该城市的感受，可能与你不同。**给配偶独立打分**。
- **子女宜居**：子女教育 + 环境 + 社交，可能与你不同。
- **父母宜居**：如果父母同住 / 附近，父母的医疗 + 气候 + 习惯。

**家庭宜居分 = 你的分 × 0.4 + 配偶分 × 0.3 + 子女分 × 0.2 + 父母分 × 0.1**

**关键**：**配偶分权重应高**，配偶不 happy 是回国返美第一原因。

## 17.7　宜居的"试住"建议

在确定城市前，建议"试住"：

1. **短期试住**：拿到 offer 后，全家去该城市试住 1-2 周，感受气候 / 通勤 / 配套 / 餐饮。
2. **不同季节**：如果可能，在不同季节试住（北京冬 / 夏差异大）。
3. **不同区位**：试住不同区位，感受通勤 + 配套差异。
4. **子女学校探访**：如有子女，探访目标学校，感受教育环境。
5. **配偶独立感受**：让配偶独立感受（购物 / 服务 / 社交），不只听你的。

**试住成本**：1-2 万人民币，远低于选错城市的成本。**强烈建议试住后再决**。

## 17.8　宜居的常见认知偏差

### 偏差一："北京空气差所以不去"

北京空气 2013-2017 差，2018 后显著改善，2024-2026 已大幅好转。**不要用 10 年前的印象判断**。

### 偏差二："深圳没文化所以不去"

深圳文化底蕴弱于北京上海，但年轻 + 搞钱 + 创新文化有独特吸引力。**文化偏好因人而异**。

### 偏差三："新一线机会少所以不去"

新一线机会密度低但产业承接强 + 房价低 + 宜居高，综合幸福度可能高于一线。**机会不是唯一指标**。

### 偏差四："宜居排行榜说 X 好所以去 X"

排行榜是综合判断，不反映你的个人权重。**按你的权重算，不要按排行榜**。

### 偏差五："配偶会适应的"

配偶不适应是回国返美第一原因。**给配偶独立打分 + 试住 + 一票否决**。

## 17.9　一个完整宜居决策案例

**背景**：海归 L6 / 一家三口 / 子女 8 岁 / 配偶工程师 / 做 AI。

**权重**（家庭协商）：

- 产业 20%（AI 机会）、教育 20%（子女）、配偶 15%（配偶就业）、住房 15%、宜居 15%（气候 + 节奏）、医疗 10%、其他 5%。

**评分**：

- 北京：产业 5 / 教育 4 / 配偶 5 / 住房 2 / 宜居 2 / 医疗 5 = 3.85
- 上海：产业 3 / 教育 5 / 配偶 5 / 住房 2 / 宜居 4 / 医疗 5 = 3.85
- 杭州：产业 4 / 教育 4 / 配偶 4 / 住房 4 / 宜居 4 / 医疗 4 = 4.0
- 成都：产业 2 / 教育 4 / 配偶 3 / 住房 5 / 宜居 5 / 医疗 4 = 3.6

**结论**：杭州 > 北京 ≈ 上海 > 成都。

**试住**：全家去杭州试住 2 周，配偶感受购物 / 服务，子女探访学校，确认后选杭州。

## 本章小结

- 宜居十维度：气候、自然、通勤、医疗、教育、文娱、安全、便利、节奏、包容。
- 个人化加权：你的宜居分 = Σ (维度分 × 权重)，权重因人而异。
- 不同画像推荐不同：单身重视机会 + 文娱，家庭重视教育 + 节奏，硬科技重视产业 + 政策。
- 长期宜居：杭州 / 成都 / 苏州 / 上海 / 广州最高。
- 家庭宜居分含配偶 + 子女 + 父母，配偶权重应高。
- 强烈建议试住 1-2 周后再决，试住成本远低于选错成本。
- 不要用旧印象 / 排行榜 / 个人偏好，按你的权重 + 试住决。
