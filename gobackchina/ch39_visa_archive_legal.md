# 第 39 章　签证 / 档案 / 法律事务

> 回国落地的法律事务繁琐但关键。本章讲签证 / 档案 / 国籍 / 出口管制 / 知识产权等法律事项。

---

## 39.1　国籍与身份决策

### 保留中国国籍（未入外籍）

- 回国无障碍 + 享公民待遇 + 落户 + 购房 + 子女入学。
- 放弃美国绿卡 / 公民（如已获）。
- **适合**：确定长期回国 + 不需回美。

### 入美国公民

- 回中国需签证（Q2 探亲 / S2 / 工作签）。
- 不能享中国公民待遇（落户 / 购房 / 子女公立受限）。
- 回美无障碍。
- **适合**：保留回美选项 + 不需中国公民待遇。

### 保留绿卡

- 回中国长期可能被认定放弃绿卡（离境 > 1 年）。
- 可申请 re-entry permit（2 年）保留。
- **适合**：回国试 1-2 年 + 想保留回美。

### 双国籍

- 中国不承认双国籍，需选一。
- **不建议**：法律风险 + 实操难。

**决策**：国籍是重大决策，涉及税务 / 身份 / 子女 / 回美，**咨询移民律师**。

## 39.2　签证（如入外籍）

### 回中国签证

- **Q2 探亲**：如中国有亲属，2 年多次，每次 90-180 天。
- **S2 私人事务**：私人事务，类似 Q2。
- **工作签（Z）**：如国内公司聘你，需工作签 + 工作许可。
- **人才签**：部分人才计划有特殊签。

### 工作许可

- 外籍人国内工作需工作许可 + 工作签。
- 公司 HR 通常代办，但需你提供材料。
- 周期：1-3 月。

### 永久居留（中国绿卡）

- 外籍可申请中国绿卡，但门槛高 + 审批严。
- 海归如保留外籍 + 长期回国可申请。
- **多数不必要**：工作签 + 续签够用。

## 39.3　档案

### 档案的重要性

档案影响落户 + 社保 + 职称 + 出境 + 国企 / 事业单位入职。

### 海归档案建立

- **留服建档**：教育部留服中心，海归最常用。
- **人才中心建档**：各地人才中心。
- **国企 / 事业单位建档**：如入职国企 / 事业单位。

### 档案材料

- 国外学历认证（留服）。
- 国外学位证 + 成绩单。
- 国内最后学历 / 工作记录。
- 身份证 + 户口。

### 调档

- 入职 / 落户需调档到单位 / 人才中心。
- 周期：1-4 周。
- **建议**：回国后立即建档 / 调档，避免需要时找不到。

## 39.4　学历认证

### 留服认证

- 教育部留服中心认证国外学历。
- 国内落户 + 求职 + 职称需。
- 周期：1-3 月。
- **建议**：回国前 3 月开始办。

### 材料

- 国外学位证 + 成绩单（原件 + 翻译）。
- 护照 + 签证 + 出入境。
- 照片 + 申请表。

## 39.5　出口管制与法律边界

### 美国出口管制

- 你在硅谷做的可能受 EAR / ITAR 管制。
- 回国做同类有法律边界，**尤其芯片 / AI / 军工**。
- **风险**：违反出口管制可能美国刑事起诉。

### 应对

- **咨询出口管制律师**：回国前确认你能做什么 / 不能做什么。
- **避免直接复制**：不把硅谷受管制的（代码 / 模型权重 / 工艺 / EDA）直接带回国。
- **独立开发**：回国后独立开发，不依赖硅谷受管制资产。
- **敏感领域慎**：芯片先进制程 / AI 大模型权重 / 军工，特别慎。

### 中国反制裁

- 中国有反外国制裁法，部分情况可能要求你配合。
- **咨询中国律师**：了解中国反制裁对你的影响。

## 39.6　知识产权与竞业

### 美国雇主 IP

- 你在硅谷雇主的 IP（代码 / 专利 / know-how）属雇主。
- 回国不能直接用，否则侵权。
- **建议**：回国前与硅谷雇主明确 IP 边界 + 不带雇主 IP。

### 竞业 / 非 solicit

- 硅谷可能有竞业 / 非 solicit（加州竞业无效，但非 solicit 可能有效）。
- 回国前确认竞业 / 非 solicit 对你的约束。
- **咨询美国律师**：确认你回国的法律边界。

### 国内雇主 IP

- 国内雇主 IP 同样属雇主。
- 离职后不能直接用。
- 国内竞业有效（部分），需注意。

### 开源 / 个人 IP

- 你个人的开源 / 专利 / 论文，确认归属。
- 部分雇主合同约定雇主 IP，需明确。

## 39.7　税务身份

### 中国税务居民

- 在中国住满 183 天，全球收入中国税。
- **建议**：回国即成为中国税务居民，规划全球收入。

### 美国税务居民

- 公民 / 绿卡：全球收入美国税，即使回国。
- 非公民 / 非绿卡：如不再满足实质居住，非美国税务居民，美国源收入才美国税。

### 双重征税

- 中美有税收协定（DTAA），避免部分双重征税。
- 但仍可能双重征税，需规划。
- **建议**：**咨询跨境税务师**，第 40 章详述。

## 39.8　子女身份

### 中国籍子女

- 落户 + 入学无障碍。
- 如子女在中国出生 + 中国籍，无障碍。

### 美国籍子女

- 回中国需签证（Q2 / S2）。
- 入学按外国人（国际学校）+ 不能享公民教育。
- 18 岁可选国籍。

### 双国籍子女

- 中国不承认，需选一。
- **建议**：子女国籍涉及教育 + 出行 + 长期，**咨询移民律师 + 与配偶商定**。

## 39.9　配偶身份

### 中国籍配偶

- 回国无障碍 + 落户 + 工作。

### 美国籍配偶

- 回中国需签证 + 工作许可（如工作）。
- 不能享中国公民待遇。

### 绿卡配偶

- 回中国长期可能影响绿卡。
- **建议**：规划绿卡保留 + 回国路径。

## 39.11　法律事务的常见坑

### 坑一：忽视出口管制

- 后果：回国做受管制方向，美国刑事风险。
- **必须咨询出口管制律师**，尤其芯片 / AI / 军工。

### 坑二：带雇主 IP

- 后果：侵权 + 被诉。
- **不带雇主 IP**，独立开发。

### 坑三：忽视竞业

- 后果：离职后被诉。
- **回国前确认竞业约束**。

### 坑四：国籍误选

- 后果：回国障碍 / 回美障碍 / 税务问题。
- **咨询移民律师**。

### 坑五：税务未规划

- 后果：双重征税 + 罚款。
- **咨询跨境税务师**。

### 坑六：子女身份未规划

- 后果：入学障碍 / 出行障碍。
- **咨询移民律师 + 早规划**。
