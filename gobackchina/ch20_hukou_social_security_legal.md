# 第 20 章　户口 / 社保 / 医疗 / 法律身份

> 这些是回国落地的"基础设施"，不性感但关键。本章把户口、社保、医疗、法律身份的实操讲清楚。

## 20.1　户口：回国落户的路径与城市差异

户口影响购房、子女入学、医疗、社保，是回国基础。

### 落户路径

1. **人才引进落户**：海归高级人才最常用，学历 + 职称 + 社保达标可落户，多数城市 1-6 月。
2. **积分落户**：按学历 + 社保 + 房产 + 年龄积分，北京 / 上海严，深圳 / 广州 / 新一线松。
3. **应届生落户**：应届博士 / 海归应届，部分城市直接落户。
4. **投靠落户**：配偶 / 父母有户口可投靠。
5. **购房落户**：部分城市购房可落户（一线多数已取消，新一线部分有）。

### 城市差异

| 城市 | 落户难度 | 海归落户路径 | 时间 |
|---|---|---|---|
| 北京 | 极难 | 人才引进（严）+ 积分（慢） | 1-3 年 |
| 上海 | 难 | 留学生落户 + 人才引进 | 6-12 月 |
| 深圳 | 较易 | 人才引进（松）+ 应届 | 1-3 月 |
| 广州 | 较易 | 人才引进 + 积分 | 3-6 月 |
| 杭州 | 易 | 人才引进（激进） | 1-3 月 |
| 成都 / 武汉 / 西安 / 合肥 / 南京 / 苏州 | 易 | 人才引进（激进） | 1-3 月 |

**关键**：**北京 / 上海户口极难，深圳 / 广州 / 新一线易**。如果户口是关键考量，优先深圳 / 新一线。

### 海归落户材料

- 国外学历认证（留服认证）。
- 国外学位证 + 成绩单。
- 护照 + 签证 + 出入境记录。
- 国内无犯罪记录（部分需）。
- 社保 + 个税记录（部分城市需）。
- 工作证明 / offer。

**建议**：回国前开始准备学历认证 + 材料，落地后立即办落户。

## 20.2　社保：五险一金

### 五险一金构成

- **养老**：个人 8% + 公司 16%，累计 15 年领养老金。
- **医疗**：个人 2% + 公司 8-10%，看病报销。
- **失业**：个人 0.5% + 公司 0.5%，失业领。
- **工伤**：公司 0.2-1.9%，工伤报销。
- **生育**：公司 0.8%，生育报销。
- **公积金**：个人 12% + 公司 12%，买房 / 租房提取。

### 海归社保的特殊问题

1. **国外社保年限**：国外社保年限通常不计入国内，回国从零缴。
2. **累计 15 年养老**：如果 40+ 回国，需缴到 55+ 才满 15 年，影响领养老金。
3. **公积金**：公积金 24% 是免税储蓄，买房 / 租房可提取，是薪酬隐性福利。
4. **跨城市转移**：社保可跨城市转移，但手续繁琐。

### 社保建议

- 落地后立即办社保，不要断缴（影响购房 / 落户 / 子女入学）。
- 公积金按 base 12% + 12% 缴，是免税储蓄，争取足缴。
- 如果 40+ 回国，考虑商业养老 / 医疗保险补充。

## 20.3　医疗：医保 + 商业保险

### 医保

- **职工医保**：公司缴，报销 70-90%，门诊 + 住院。
- **居民医保**：无业 / 灵活就业，报销 50-70%，需自缴。
- **公费医疗**：部分国企 / 公务员，报销高。

### 商业保险

- **补充医疗**：大厂多数提供，覆盖医保外。
- **百万医疗**：自购，年 300-1000 元，保 100-600 万。
- **重疾险**：自购，年 5000-20000 元，确诊重疾一次性给。
- **寿险 / 意外**：自购，家庭保障。

### 海归医疗建议

- 落地后立即办医保，不要裸奔。
- 大厂补充医疗 + 自购百万医疗 + 重疾，三层覆盖。
- 如果有慢性病 / 家族病史，优先重疾 + 百万医疗。
- 子女医保 + 商业保险（大厂子女保险或自购）。

### 医疗资源

- **一线**：三甲 + 专科顶级（协和 / 北医 / 瑞金 / 华山），但挂号难。
- **新一线**：三甲好（浙一 / 川大 / 华西），挂号好于一线。
- **建议**：了解目标城市三甲 + 专科，注册互联网医疗（好大夫 / 微医）方便挂号。

## 20.4　法律身份：身份证 / 护照 / 永久居留

### 身份证

- 回国落户后办身份证，是基础身份。
- 如果之前有身份证，确认是否有效 + 更新。

### 护照

- 中国护照：如果入外籍需注销中国户籍 + 签证回中国。
- **海归常见问题**：是否入外籍？入外籍回国需签证 + 不能享公民待遇。

### 永久居留（中国绿卡）

- 中国有"外国人永久居留"（中国绿卡），但门槛高 + 审批严。
- 海归如果保留外籍，可申请中国绿卡，但多数不必要。

### 国籍选择

- **保留中国国籍**：回国无障碍 + 享公民待遇，但放弃美国公民 / 绿卡。
- **入美国公民**：回中国需签证 + 不能享公民待遇，但保留美国身份。
- **保留绿卡**：回国可能影响绿卡（长期离境可能被认定放弃），需规划。

**建议**：国籍选择是重大决策，涉及税务 / 身份 / 子女 / 回美，**咨询移民律师**，第 39 章详述。

## 20.5　档案：被忽视但关键

档案影响落户 + 社保 + 职称 + 出境：

- **档案在哪**：国企 / 事业单位 / 人才中心 / 留服。
- **海归档案**：留服建档 or 人才中心建档。
- **调档**：入职 / 落户需调档，手续繁琐。
- **建议**：回国后立即建档 / 调档，避免落地后需要时找不到。

## 20.6　职称：海归认证

职称影响落户 + 薪酬 + 晋升：

- **国外职称认证**：留服可认证国外学位 / 职称。
- **国内职称**：工程师 / 高工 / 教授，需评审。
- **海归通道**：部分城市海归可直接认定高级职称。
- **建议**：回国后认证国外学位 + 申请职称认定，利好落户 + 薪酬。

## 20.7　子女身份

子女身份影响入学 + 出行：

- **中国籍子女**：落户 + 入学无障碍。
- **美国籍子女**：回中国需签证 + 入学按外国人（国际学校）+ 不能享公民教育。
- **双国籍**：中国不承认双国籍，需选一。
- **建议**：子女国籍选择涉及教育 + 出行 + 长期，**咨询移民律师 + 与配偶商定**。

## 20.8　税务身份

税务身份影响全球征税：

- **中国税务居民**：在中国住满 183 天，全球收入中国税。
- **美国税务居民**：公民 / 绿卡 / 满足实质居住测试，全球收入美国税。
- **双重征税**：中美有税收协定，但仍可能双重征税，需规划。
- **建议**：回国前咨询跨境税务师，规划税务身份 + 避免双重征税，第 40 章详述。

## 20.9　一个完整身份落地案例

**背景**：海归 L6 / 中国籍 / 配偶中国籍 / 子女美国籍 / 回杭州。

**落地清单**：

1. **学历认证**：回国前 3 月办留服学历认证。
2. **落户**：落地后 1 月办人才引进落户（杭州松，1-3 月）。
3. **身份证**：落户后办身份证。
4. **社保**：入职后立即办五险一金，足缴公积金。
5. **医保**：职工医保 + 大厂补充医疗 + 自购百万医疗 + 重疾。
6. **档案**：留服建档 + 调档到杭州人才中心。
7. **职称**：申请高级工程师认定。
8. **子女身份**：子女美国籍，办中国签证 + 入读国际学校。
9. **税务**：咨询跨境税务师，规划中美税务。
10. **配偶**：配偶同步办落户 + 社保 + 档案。

**时间**：1-3 月完成基础，6 月全部到位。
