# 第 34 章　当下市场严峻性冷启动分析

> 不带滤镜地看 2025-2026 国内科技求职市场的真实严峻性。本章给冷启动分析，避免冲动。

> ⚠️ **本章数字声明**：本章出现的薪酬/offer/缩编比例等具体数字，均来源于 2024-2026 年互联网公开信息（脉脉、看准网、知乎、公司披露、媒体报道等）的综合估算，**并非任何公司官方标准，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

---

## 34.1　2025-2026 国内科技市场真实状态

### 整体

- 互联网大厂整体在"降本增效"周期，HC 紧 + 裁员持续。
- AI 局部 war for talent，但整体 HC 仍紧。
- 创业公司融资难 + 死亡率高。
- 芯片仍扩张但开始分化。
- 外企在华收缩。

### 大厂 HC

- 阿里 P8 外部招几乎冻结，P7 主流。
- 腾讯 T11+ 紧，T10 主流。
- 字节 5-1+ 紧但 AI 方向有，4-1 主流。
- 华为 18+ 有（芯片 / 2012），17 主流。
- 美团 / 京东 / 百度 / 小米 / 网易高级 HC 紧。

### AI 六小虎

- 2023-2025 扩张，2026 开始收缩 + 部分裁员。
- 海归溢价降但仍在，需选对公司。
- 估值泡沫 + 商业化承压。

### 芯片

- 2024-2027 仍扩张，海归溢价最高。
- 但开始分化，部分公司承压。
- 审查趋严 + 地缘政治。

### 创业

- 融资难（比 2020-2021 难很多）。
- 死亡率高（AI 应用层 > 50%）。
- 海归去创业需更谨慎。

## 34.2　海归求职的真实难度

### 高级岗（P8+ / 5-1+ / 18+）

- HC 极紧，VP 审批。
- 海归议价空间在稀缺方向（AI / 芯片 / infra），generalist 难。
- 需内推 / 猎头 / 专家通道，海投无效。
- **难度**：高，但稀缺方向可。

### 中级岗（P7 / 4-1 / 17）

- HC 紧但仍有，海归主流落点。
- 议价空间中，竞争烈。
- **难度**：中高。

### 初级岗（P6 / 3-2 / 16）

- HC 砍半 +，应届 + 初级难。
- 海归初级不推荐（国内初级更便宜 + AI 替代）。
- **难度**：高，且海归无优势。

### AI 方向

- 仍有需求但 2026 收缩，需选对公司。
- 六小虎 + 大厂 lab，海归溢价在但降。
- **难度**：中，选对是关键。

### 芯片方向

- 仍扩张，海归溢价最高。
- 但审查严 + 地缘政治。
- **难度**：中，方向匹配是关键。

### generalist

- HC 紧 + AI 替代 + 海归无优势。
- **难度**：高，不推荐海归首选。

## 34.3　市场严峻的五个表现

1. **HC 紧**：高级岗 VP 审批 + 名额少。
2. **裁员持续**：大厂 + 创业 + 外企都在裁。
3. **薪酬水位平 / 降**：2022 顶配不再，2025-2026 平 / 略降。
4. **晋升难**：P7→P8 / T10→T11 通过率降。
5. **跳槽难**：HC 紧 + 计价弱 + 背景调查严。

## 34.4　严峻市场的海归策略

### 策略一：选对方向

- AI / 芯片 / infra / 出海：需求在 + 海归溢价。
- generalist / 执行型：避开。
- **方向选择权重最高**。

### 策略二：选对公司

- 财务稳 + 战略方向 + HC 稳的公司。
- 避开：裁员史 + 财务差 + 边缘业务。
- 大厂核心 + 芯片 + AI 六小虎（选对）+ AI infra。

### 策略三：选对通道

- 内推 / 猎头 / 专家通道，不海投。
- 第 22-24 章方法。
- 海归专项 / 顶级人才通道。

### 策略四：议价现实

- 2022 顶配不再，2025-2026 现实预期。
- 不按 2022 水位期望，按 2026 水位谈。
- 但稀缺方向仍可议价（第 11 章）。

### 策略五：多 offer + 多渠道

- 多 offer 议价强 + 风险分散。
- 多渠道（内推 + 猎头 + 直联）。
- 不 all-in 一家。

### 策略六：备选 + 可逆

- 保留在美选项 / 返美路径。
- 不 all-in 回国，有备选。
- 降低不可逆决策。

## 34.5　严峻市场的"不该做"

### 不该一：冲动回国

- 市场严峻 + 冲动 = 高危。
- 充分调研 + 家属同步 + 心理准备后再决。

### 不该二：generalist 海归

- generalist HC 紧 + 海归无优势。
- 除非升级到系统设计 / 管线。

### 不该三：去边缘业务

- 边缘业务裁员风险高 + 无竞争力。
- 选核心 + 战略方向。

### 不该四：去财务差的公司

- 财务差 = 裁员 / 欠薪 / 解散风险。
- 选财务稳。

### 不该五：放弃议价

- 严峻不等于不能议价。
- 稀缺方向 + 多 offer 仍可议价。

### 不该六：all-in 一家

- all-in 一家 = 风险集中。
- 多 offer + 多渠道 + 备选。

## 34.6　严峻市场的"仍可做"

### 仍可一：稀缺方向海归

- AI / 芯片 / infra / 出海，需求在 + 溢价。
- 选对方向仍好时机。

### 仍可二：高级 + 系统设计

- L6+ 系统设计 + 管线，AI 难替代 + 需求在。
- 高级 + 稀缺仍好。

### 仍可三：内部 transfer

- 外企内部 transfer，避开市场严峻。
- 最低风险路径。

### 仍可四：创业（谨慎）

- AI infra / 芯片等刚需创业仍可。
- 但需强尽调 + 备选 + 绿卡保底。

### 仍可五：高校 / 研究所

- 人才计划 + 稳定 + AI 战略。
- 博士 + 顶会仍好。

## 34.7　市场何时回暖

本书不预测，但给判断框架：

### 短期（2026-2027）

- 互联网大厂可能局部放松，但整体紧。
- AI 可能整合 + 寡头，海归机会减。
- 芯片仍扩张。
- **判断**：局部回暖，但整体仍紧。

### 中期（2027-2029）

- 取决于 AI 商业化 + 利率 + 地缘政治。
- 如 AI 商业化顺 + 利率降，可能回暖。
- 如地缘政治恶化，可能更紧。
- **判断**：不确定，需持续观察。

### 长期（2029+）

- AI 时代新均衡，部分岗位消失 + 部分新增。
- 系统设计 + 管线 + 稀缺方向长期好。
- generalist + 执行型长期难。
- **判断**：结构分化，不是整体回暖。

**结论**：**不要等"市场回暖"再回**，市场不会回到 2020-2021。**在当前市场选对方向 + 公司 + 通道，仍可好时机**。

## 34.8　严峻市场的心理调适

严峻市场易引发焦虑 / 冲动 / 失望：

### 调适一：现实预期

- 不按 2020-2021 顶配期望。
- 接受 2025-2026 现实水位。
- 现实预期减少失望。

### 调适二：长期视角

- 不只看当前市场，看 5-10 年长期。
- 系统设计 + 稀缺方向长期好。
- 长期视角减少短期焦虑。

### 调适三：主动 + 掌控

- 主动调研 + 求职 + upskill，不被动等。
- 掌控感减少焦虑。

### 调适四：多元价值

- 不只工作 + 薪酬，家庭 + 健康 + 兴趣 + 关系多元。
- 多元价值减少单一焦虑。

### 调适五：支持系统

- 家属 + 朋友 + 海归圈 + 心理咨询。
- 不孤立应对。

## 34.9　一个严峻市场海归决策案例

**背景**：海归 L6 / 36 岁 / 在美 10 年 / 做大模型推理优化 / 绿卡已批 / 已婚一子 6 岁。

**市场评估**：

- AI 2026 收缩但推理优化仍稀缺。
- 字节豆包 / 阿里通义 / AI infra 创业都有需求。
- 高级 + 稀缺方向仍可议价。

**决策**：

1. **方向**：推理优化（稀缺 + AI infra 刚需），不转 generalist。
2. **公司**：多 offer（字节豆包 + 阿里通义 + 硅基流动），选对 + 计价。
3. **通道**：内推（前同事在字节）+ 猎头（AI 专注），不海投。
4. **议价**：多 offer + 稀缺方向，仍可议价（第 11 章）。
5. **备选**：保留在美选项（绿卡 + 房产 + 401k），不 all-in。
6. **心理**：现实预期 + 长期视角 + 主动 + 多元 + 支持。

**结果**：在严峻市场仍拿到好 offer（字节 5-1，350 万），因选对方向 + 多 offer + 议价。

## 本章小结

- 2025-2026 国内科技市场整体严峻：HC 紧 + 裁员 + 薪酬平 + 晋升难 + 跳槽难。
- 海归求职难度：高级紧但稀缺可，中级中高，初级高无优势，AI 中选对关键，芯片中，generalist 高。
- 五严峻表现：HC 紧、裁员、薪酬平、晋升难、跳槽难。
- 六策略：选对方向、选对公司、选对通道、议价现实、多 offer、备选可逆。
- 六不该：冲动、generalist、边缘、财务差、放弃议价、all-in。
- 五仍可：稀缺方向、高级系统设计、内部 transfer、谨慎创业、高校。
- 不要等回暖，当前市场选对仍可。
- 心理调适：现实预期、长期视角、主动、多元、支持。
