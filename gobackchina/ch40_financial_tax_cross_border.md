# 第 40 章　财务规划 / 税务 / 资产跨境

> 回国是一次重大财务事件。本章讲在美资产处置 + 跨境资金 + 中美税务 + 长期财务规划。

> ⚠️ **本章数字声明**：本章出现的薪酬/税率/房产价值/投资额等具体数字，均来源于 2024-2026 年互联网公开信息（IRS、国税总局、知乎、媒体报道等）的综合估算，**并非官方数据，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。涉及具体税务/资产决策时务必咨询持牌专业人士。

## 40.1　在美资产处置

### 房产

- **卖**：变现 + 简化 + 回国资金。但交易成本 + 税 + 卖时差。
- **租**：保留 + 长期 + 回美备选。但远程管理 + 租管 + 税。
- **建议**：
  - 确定长期回国 → 卖（变现 + 简化）。
  - 不确定 / 想保留回美 → 租（保留 + 备选）。
  - 卖时差：回国前 6-12 月挂卖，避免急卖折价。

### 401k / IRA

- **保留**：留美国账户 + 59.5 岁取。
- **提前取**：10% 罚款 + 税，慎。
- **rollover**：可 rollover 到 IRA，但需合规。
- **建议**：保留美国账户 + 59.5 取，不提前取。

### RSU / 期权

- **已归属**：可卖 + 跨境汇回。
- **未归属**：离职后通常取消（部分公司允许继续 vesting，需确认）。
- **建议**：回国前卖已归属 + 确认未归属处理 + 跨境汇回。

### 股票 / 基金 / 银行账户

- **保留**：留美国账户 + 跨境用 + 长期。
- **卖**：变现 + 跨境汇回（按需）。
- **建议**：保留美国账户 + 跨境用 + 不全关。

### 车 / 物品

- **卖**：车 / 大件卖 + 简化。
- **运**：贵重 / 纪念运回。
- **建议**：卖车 / 大件 + 运少量。

## 40.2　跨境资金

### 美国汇中国

- **个人额度**：每人每年 5 万美元购汇 + 汇出。
- **亲属额度**：父母 / 配偶 / 成年子女各有 5 万，可合计。
- **大额**：超 5 万需分年 / 亲属 / 合规渠道。
- **银行**：中国银行 / 招行 / 工行等，跨境汇款。
- **申报**：超 5 万美元需国际收支申报。
- **建议**：提前 1-2 年规划大额汇回 + 用亲属额度 + 合规渠道。

### 中国汇美国

- **额度**：每人每年 5 万美元购汇 + 汇出。
- **大额**：同上，分年 / 亲属。
- **建议**：如需汇美（子女留学 / 资产），提前规划。

### 跨境税务申报

-<br>- **美国**：FBAR（海外账户 > 1 万美元申报）+ FATCA（海外资产申报）。
- **中国**：CRS（全球收入申报）+ 个税申报。
- **建议**：**咨询跨境税务师**，合规申报 + 避重罚。

## 40.3　中国税务

### 个税

- **税率**：7 级累进，3-45%。
- **综合所得**：工资 + 薪酬 + 经营 + 稿酬 + 特许权 + 利息 + 股息 + 财产租赁 + 财产转让。
- **专项扣除**：子女教育 / 继续教育 / 大病医疗 / 房贷利息 / 住房租金 / 赡养老人。
- **专项附加扣除额度**：子女教育 1000-2000 / 月 / 个、继续教育 400 / 月或 3600 / 年、房贷 1000 / 月、租金 800-1500 / 月、老人 2000-3000 / 月 / 个。
- **建议**：用足专项扣除 + 专项附加扣除 + 公积金，降税。

### 公积金

- **免税**：个人 12% + 公司 12% 免税。
- **提取**：买房 / 租房 / 退休可提取。
- **建议**：足缴公积金 + 用足免税。

### 股权税

- **RSU vesting**：按市价计个人所得税（最高 45%）。
- **期权行权**：按（行权日市价 - 行权价）计税，复杂 + 重。
- **TUP 分红**：按股息红利税 20%。
- **资本利得**：卖出按 20%（长期 > 1 年）或并入综合（短期）。
- **优化**：
  - **sell to cover**：vesting 时卖一部分交税。
  - **83(b) election**：部分情况早期行权 + 83(b) 降税。
  - **长期持有**：> 1 年资本利得 20% < 短期 45%。
  - **股权激励递延**：部分公司有递延政策。
- **建议**：**咨询股权税务师**，规划股权税 + 省 10-30%。

### 年终奖 + sign-on

- **一次性奖金计税**：年终奖 / sign-on 可走"一次性奖金"单独计税，税负低于并入综合。
- **建议**：年终奖 / sign-on 走一次性计税 + 与综合所得比，选低。

## 40.4　美国税务（如仍美国税务居民）

### 全球收入

- 公民 / 绿卡：全球收入美国税，即使回国。
- **外国收入排除**：Foreign Earned Income Exclusion 约 12 万美元 / 年（2024）+ 外国住房排除。
- **外国税抵免**：Foreign Tax Credit，已交中国税可抵美国税，避免双重征税。
- **建议**：用足排除 + 抵免 + DTAA，**咨询跨境税务师**。

### FBAR / FATCA

- **FBAR**：海外账户 > 1 万美元申报（FinCEN 114）。
- **FATCA**：海外资产申报（8938）。
- **建议**：合规申报 + 避重罚（FBAR 未申报罚可达 10 万美元 / 年）。

### 放弃绿卡 / 公民

- 如放弃绿卡 / 公民，可能"expatriation tax"（视同卖出所有资产 + 税）。
- **建议**：放弃前咨询税务师 + 规划 expatriation tax。

## 40.5　长期财务规划

### 现金流

- **月现金流**：税后收入 - 生活成本 - 房供 - 教育 = 净现金流。
- **应急金**：6-12 月生活 + 房供 + 教育，存现金 / 货币基金。
- **储蓄率**：净现金流 / 税后收入，目标 > 30%。

### 投资

- **资产配置**：股票 / 债券 / 房产 / 现金，按年龄 + 风险。
- **国内**：A 股 / 港股 / 公募 / 私募 / 房产 / 银行理财。
- **美国**：美股 / 美基 / 401k / IRA（如保留）。
- **跨境**：中美资产配置 + 税务规划。
- **建议**：分散 + 长期 + 低成本指数为主。

### 保险

- **医疗**：医保 + 百万医疗 + 重疾 + 商业养老。
- **寿险 / 意外**：家庭保障。
- **财产**：房 + 车。
- **建议**：三层覆盖 + 家属 + 子女。

### 退休

- **中国**：社保养老 + 企业年金 + 个人养老金（第三支柱）+ 商业养老。
- **美国**：社保 + 401k + IRA（如保留）。
- **建议**：多支柱 + 早规划 + 跨境规划。

### 子女教育金

- **估算**：国际学校 200-600 万 + 大学 100-300 万。
- **工具**：教育金保险 / 基金 / 定投 / 信托。
- **建议**：早规划 + 专款 + 长期。

### 房产

- **自住**：第 15 章模型。
- **投资**：核心地段 + 长期 + 杠杆适度。
- **建议**：先自住 + 后投资 + 不过度。

## 40.6　财务规划的"海归特殊"

### 跨境资产

- 中美资产 + 税务 + 申报复杂。
- **建议**：跨境税务师 + 合规 + 规划。

### 双重征税

- 中美 DTAA + 排除 + 抵免，但仍可能双重。
- **建议**：跨境税务师 + 用足协定。

### 汇率风险

- 中美资产汇率波动。
- **建议**：分散 + 对冲 + 长期。

### 政策风险

-@- 中美政策变动 + 跨境限制。
- **建议**：关注政策 + 灵活 + 合规。

## 40.7　一个完整财务规划案例

**背景**：海归 L6 /3 /0 / 回字节 5-1 / 年 350 万 / 一家三口 / 在美房产 150 万美元 + 401k 30 万 + RSU 50 万美元。

### 在美资产处置

- 房：租（保留 + 回美备选），租管 + 远程。
- 401k：保留 + 59.5 取。
- RSU：回国前卖已归属 + 跨境汇回（分 2 年 + 亲属额度）。

### 跨境资金

- 卖 RSU 50 万美元 + 亲属额度 2 年汇回 100 万美元 → 约 700 万人民币。
- 合规申报 FBAR / FATCA。

### 中国税务

- 年 350 万，税后约 280 万。
- 专项扣除：子女 2 万 + 房贷 12 万 + 老人 4 万 = 18 万。
- 公积金：base 12% + 12% 免税。
- sign-on 30 万走一次性计税 + 省。
- 股权 vesting sell to cover + 长期持有资本利得。

> **注**：本节数字为示意，实际税务请以最新税法 + 跨境税务师计算为准。

### 现金流

- 税后 280 万 - 生活 100 万 - 房供 30 万 - 教育 25 万 = 净 125 万。
- 应急金：12 月 × 25 万 = 300 万，存现金 / 货币基金。
- 储蓄率：125 / 280 = 45%，达标。

### 投资

- 国内：A 股指数 + 公募 + 房产。
- 美国：保留 401k + 美基。
- 跨境：中美配置 + 税务规划。

### 保险

- 医保 + 百万医疗 + 重疾 + 寿险 + 财产，三层覆盖。

### 子女教育金

- 国际学校 25 万 / 年 + 大学 200 万，教育金保险 + 定投。

**结果**：财务规划就绪 + 税务合规 + 现金流正 + 长期规划。

## 40.8　财务规划的常见坑

### 坑一：未规划跨境

- 后果：大额汇不回 / 申报漏 / 罚款。
- **提前 1-2 年规划 + 跨境税务师**。

### 坑二：忽视 FBAR / FATCA

- 后果：重罚（FBAR 10 万美元 / 年）。
- **合规申报**。

### 坑三：股权税未规划

- 后果：多交 10-30% 税。
- **股权税务师 + sell to cover + 83(b) + 长期持有**。

### 坑四：应急金不足

- 后果：被裁 / 意外被动。
- **6-12 月应急金**。

### 坑五：过度房产

- 后果：现金流紧 + 流动性差。
- **先自住 + 后投资 + 不过度**。

### 坑六：忽视汇率 / 政策风险

- 后果：资产损失。
- **分散 + 关注政策**。

- 在美资产：房卖 / 租、401k 保留、RSU 卖 + 汇回、账户保留。
- 跨境资金：5 万美元 / 年 / 人 + 亲属额度 + 合规申报。

- 长期规划：现金流 + 应急 + 储蓄率 + 投资 + 保险 + 退休 + 教育金 + 房产。
- 海归特殊：跨境资产 + 双重征税 + 汇率 + 政策。
- **强烈建议咨询跨境税务师 + 移民律师 + 财务规划师**，省 10-30% 税 + 避重罚 + 长期安全。
