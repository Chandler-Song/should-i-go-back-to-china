# 第 36 章　回国实操 Checklist（90 天版）

> 把前 35 章浓缩成一份可执行的 90 天 checklist。从决策到落地，每周做什么、每项谁负责、如何验证。

---

## 36.1　Checklist 使用说明

- **前提**：你已完成第 25-26 章动机确认 + 第 29 章时机评估，决定回国。
- **90 天**：从"开始求职"到"落地入职"的紧凑版。如时间宽裕可拉长到 6-12 月。
- **并行**：多项并行，不是严格串行。
- **家属**：家属同步进行，标注 [家属] 的项需家属参与。
- **验证**：每项有验证标准，不走过场。

## 36.2　第 1-2 周：信息刷新 + 简历 + 渠道建立

### 信息刷新

- [ ] 用第 21 章方法刷新目标公司 / 赛道 / 薪酬 / 政策（决策前 1 月内）。
- [ ] 三角验证 3-5 个关键判断（薪酬 / HC / 文化）。
- [ ] 反确认：找 1-2 个负面信息源。
- **验证**：Notion 整理，决策就绪信息包。

### 简历本土化

- [ ] 用第 37 章方法改造简历（中文 + 国内格式 + 量化）。
- [ ] 准备 2-3 版（不同公司 / 方向）。
- [ ] 准备英文版（外企 / 国际化岗）。
- **验证**：简历经 2-3 人 review。

### 渠道建立

- [ ] 列人脉清单（第 22 章），激活旧 + 建新。
- [ ] 联系 2-3 个专注猎头（第 24 章）。
- [ ] 加海归微信群（公司 / 城市 / 校友）。
- **验证**：20+ 有效人脉 + 2+ 猎头。

### [家属] 同步

- [ ] 与家属深度沟通决策 + 时间线。
- [ ] 家属独立评估（职业 / 城市 / 教育）。
- [ ] 家属一票否决确认。
- **验证**：家属真心同意 + 无被动。

## 36.3　第 3-6 周：投递 + 面试准备 + 访谈

### 投递

- [ ] 通过内推投 5-10 个目标岗位（第 22 章）。
- [ ] 通过猎头投 3-5 个（第 24 章）。
- [ ] 直联 hiring manager 2-3 个（LinkedIn）。
- **验证**：10+ 投递，5+ 面试邀约。

### 面试准备

- [ ] 用第 38 章方法准备（技术 + 系统 + 行为 + 国内特色）。
- [ ] 模拟面试 3-5 次（朋友 / 猎头 / 自己）。
- [ ] 准备问面试官的问题（第 23 章）。
- **验证**：模拟反馈好 + 自信。

### 访谈

- [ ] 访谈 3-5 个在目标公司 / 团队的人（第 23 章）。
- [ ] 整理访谈信息 + 交叉验证。
- **验证**：目标公司 / 团队微观认知就绪。

### [家属] 城市试住

- [ ] 全家去目标城市试住 1-2 周（第 17 章）。
- [ ] 探访子女学校 + 配偶潜在工作 + 住房。
- **验证**：全家对城市有好感 + 无否决。

## 36.4　第 7-10 周：面试 + 谈判

### 面试

- [ ] 完成 5-10 个面试流程。
- [ ] 每面试后复盘 + 调整。
- [ ] 保持多流程并行。
- **验证**：2-3 个 offer / final。

### 谈判

- [ ] 用第 11 章方法谈每个 offer。
- [ ] 多 offer 互相 match / beat。
- [ ] 逐项谈（base / 股权 / sign-on / 级别）。
- [ ] 一切写进 offer。
- **验证**：拿到 1-2 个满意 offer。

### 公司 / 团队最终尽调

- [ ] 对最终 offer 公司 / 团队做深度尽调（第 05 章 8 项）。
- [ ] 与 hiring manager 深谈 + 问团队 / 资源 / 期望。
- **验证**：无红旗 + 高置信。

### [家属] 最终同步

- [ ] 与家属分享 offer + 城市 + 公司。
- [ ] 家属最终同意 + 无否决。
- **验证**：家属全力支持。

## 36.5　第 11-12 周：决策 + 签约 + 落地准备

### 决策

- [ ] 用第 01 章五因子 + 第 25 章心理准备度最终评估。
- [ ] 与家属共同决策。
- [ ] 接受 offer + 签约。
- **验证**：签约 + 无犹豫。

### 落地准备

- [ ] 学历认证（留服）。
- [ ] 签证 / 档案 / 身份（第 39 章）。
- [ ] 在美资产处置（房产 / 401k / RSU / 账户，第 40 章）。
- [ ] 跨境资金规划（第 40 章）。
- [ ] 税务规划（第 40 章）。
- [ ] 搬迁公司 + 物流。
- **验证**：落地行政就绪。

### [家属] 落地准备

- [ ] 配偶职业安排（求职 / 全职 + 财务）。
- [ ] 子女学校申请 + 录取。
- [ ] 住房安排（先租 1 年）。
- [ ] 配偶 / 子女身份 + 签证。
- **验证**：家属落地就绪。

## 36.6　第 13 周：落地 + 入职

### 落地

- [ ] 抵达 + 入住临时住房。
- [ ] 办落户 + 身份证 + 社保 + 公积金（第 20 章）。
- [ ] 办银行卡 + 手机 + 交通。
- [ ] 子女入学。
- [ ] 配偶安顿。
- **验证**：基础生活就绪。

### 入职

- [ ] 报到 + 入职手续。
- [ ] 了解团队 + 业务 + 文化。
- [ ] 建 30-60-90 天计划。
- **验证**：入职顺利 + 30 天计划。

## 36.7　落地后 30-60-90 天

### 30 天

- [ ] 适应工作 + 团队 + 文化。
- [ ] 建内部人脉（同事 + 跨团队）。
- [ ] [家属] 配偶建社交圈 + 子女适应学校。
- [ ] 密切关注家属情绪 + 必要时支持。
- **验证**：基本适应 + 家属稳定。

### 60 天

- [ ] 产出第一个贡献（项目 / feature / 优化）。
- [ ] 深化人脉 + 海归圈。
- [ ] [家属] 配偶独立活动 / 工作 / 兴趣。
- **验证**：有贡献 + 家属适应。

### 90 天

- [ ] 稳定工作节奏 + 绩效轨道。
- [ ] 住房长租 / 考虑购房（第 15 章）。
- [ ] [家属] 全家适应 + 支持网建立。
- [ ] 心理 check-in（第 25-28 章）。
- **验证**：90 天稳定 + 不后悔。

## 36.8　Checklist 的"红线"

以下任一出现，**暂停 / 重新评估**：

1. 家属明确反对 / 一票否决。
2. 面试全拒 / 无 offer。
3. offer 远低于预期（< 70%）。
4. 尽调发现重大红旗（财务差 / 裁员 / 文化毒）。
5. 心理准备度 < 15（第 25 章）。
6. 情绪驱动（近期重大负面）。
7. 不可逆变量 unfavorable（绿卡排期 / 子女 15+）。

## 36.9　Checklist 的"加速器"

以下可加速：

1. 内推强（直接面试 + 议价）。
2. 内部 transfer（外企，跳过面试）。
3. 稀缺方向（议价强 + HC 宽）。
4. 绿卡已批（可逆性高）。
5. 家属全力支持（无阻力）。
6. 现金充裕（不急于签约）。

## 36.10　Checklist 的常见坑

### 坑一：跳过家属同步

- 后果：落地后家属反悔 + 返美。
- **必须家属全程同步**。

### 坑二：信息不刷新

- 后果：用旧信息决策 + 踩坑。
- **决策前 1 月刷新**。

### 坑三：海投

- 后果：响应率低 + 议价弱。
- **内推 + 猎头 + 直联**。

### 坑四：单 offer

- 后果：无议价 + 风险集中。
- **多 offer 并行**。

### 坑五：口头承诺

- 后果：落地后不兑现。
- **一切写进 offer**。

### 坑六：立刻买房

- 后果：选错 + 锁死。
- **先租 1 年**。

### 坑七：忽视心理

- 后果：适应期崩溃。
- **第 25-28 章必须读 + 心理准备**。

## 本章小结

- 90 天 checklist：信息刷新 → 投递 → 面试 → 谈判 → 决策 → 落地 → 30-60-90。
- 家属全程同步，给一票否决。
- 多 offer 并行，内推 + 猎头 + 直联，不海投。
- 一切写进 offer，先租 1 年。
- 红线：家属反对、无 offer、远低预期、红旗、心理未备、情绪、不可逆。
- 加速器：内推、内部 transfer、稀缺、绿卡、家属支持、现金。
- 七坑：跳家属、不刷新、海投、单 offer、口头、立刻买房、忽视心理。
