# 第 03 章　第二梯队大厂深度：美团 / 京东 / 百度 / 小米 / 网易

> 第二梯队常被海归忽视，但其中藏着被低估的机会——尤其对追求 WLB、想进特定赛道、或拿不到第一梯队顶级 offer 的人。本章拆五家的真实海归价值。

> ⚠️ **本章数字声明**：本章出现的薪酬/总包/股权等具体数字，均来源于 2024-2026 年互联网公开信息（Levels.fyi、脉脉、看准网、知乎、公司披露、媒体报道等）的综合估算，**并非任何公司官方标准，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

## 3.1　为什么认真考虑第二梯队

第一梯队光环太重，很多海归非字节不去、非阿里不看。这是一个信息偏差。第二梯队的真实价值：

1. **WLB 普遍更好**：网易、百度、京东的平均强度显著低于字节华为。
2. **特定赛道第一**：美团在本地生活、京东在供应链物流、百度在自动驾驶、小米在 IoT 硬件、网易在游戏，都是各自领域第一梯队。
3. **海归议价空间反而大**：第一梯队海归扎堆，议价被压；第二梯队海归稀缺，HR 更愿意为海归开特批。
4. **已上市 equity 确定**：五家全部已上市，RSU 流动性好。
5. **文化冲击小**：组织相对成熟，对海归的"硅谷习惯"包容度更高。

代价是：技术深度和资源量不如第一梯队，AI 投入除百度外都不算激进。**第二梯队是"性价比选"，不是"冲顶选"**。

## 3.2　美团：本地生活第一，技术被低估的一个

### 业务与组织基因

美团是**本地生活 + 即时配送 + 到店酒旅**的绝对龙头。基因：

- **超大脑 + 大中台**：王兴时代的工程文化，技术投入认真，配送调度算法是国内最复杂的实时系统之一。
- **"以科学和技术追求真理"**：美团的技术文化在第二梯队里最像硅谷，数据驱动、A/B 实验文化深。
- **近年调整**：2024 年组织调整后，核心本地生活 + 美团优选 + Keeta（香港出海）三条线。

### 海归偏好与岗位

- **配送 / 调度算法**：LBS、运筹、实时调度，对硅谷做 maps / routing / 运筹的人极友好。
- **搜索 / 推荐 / 广告**：到店业务的搜推广告，对硅谷做 ranking 的人友好。
- **Keeta / 出海**：香港、沙特 Keeta，对海归 + 出海经验直接复用。
- **基础架构 / 数据**：美团自研的 OctoBase、Cellar、Squirrel，对硅谷 infra 背景友好。

**劝退点**：美团的 AI 大模型投入不如第一梯队激进（自研 LongCat 但规模小），纯 AI 算法岗不如去字节。北京望京 / 美团总部地点一般。

### 薪酬与级别

美团职级 L4-L14（新体系），海归常见落点：

| 海归背景 | 美团职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | L7 / L8 | 55-85 万 | 20-40 万 | 75-125 万 |
| 硅谷 L6 / 8 年 | L9 / L10 | 90-150 万 | 60-150 万 | 150-300 万 |
| 硅谷 L7+ / 12 年+ | L11 / L12 | 150-250 万 | 150-350 万 | 300-600 万 |

美团已上市，RSU 流动性好。海归议价空间在第二梯队里最大，因为本地生活赛道对海归天然稀缺。

### 工作体感

- **优点**：技术文化好、数据驱动、WLB 中等偏好、配送算法国内顶级、已上市 equity。
- **缺点**：AI 投入不激进、北京望京地点一般、近年业务承压（抖音生活服务竞争）。
- **适合**：做调度 / 运筹 / LBS / 搜推、重视技术文化、可接受 AI 不是主战场的人。

## 3.3　京东：供应链物流第一，技术被低估更严重的一个

### 业务与组织基因

京东是**自营电商 + 供应链物流 + 健康金融**的龙头。基因：

- **重资产运营**：亚洲一号、无人仓、自研物流，工程投入极认真。
- **技术被低估**：京东的物流自动化、供应链算法、亚洲一号的机器人系统，技术含量国内顶级，但外界常以为京东"只是卖货的"。
- **近年调整**：许冉时代降本增效，但京东工业、京东健康、京东国际仍在扩张。

### 海归偏好与岗位

- **供应链 / 运筹 / 物流自动化**：对硅谷做 supply chain / robotics / warehouse automation 的人极友好，国内几乎唯一大规模。
- **京东云 / 言犀大模型**：京东云 + 言犀，对硅谷 infra / NLP 背景有需求，但规模不如阿里云。
- **京东健康 / 工业**：垂直 to B，对硅谷相应行业背景的人友好。
- **京东国际 / 出海**：joybuy 欧洲 / 东南亚，对海归 + 出海经验复用。

**劝退点**：京东的技术品牌力弱于阿里美团，且近年增长承压，HC 收紧。北京亦庄总部地点偏远。

### 薪酬与级别

京东职级 T5-T12（参考阿里体系），海归常见落点：

| 海归背景 | 京东职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | T7 | 50-80 万 | 15-30 万 | 65-110 万 |
| 硅谷 L6 / 8 年 | T8 / T9 | 80-140 万 | 50-120 万 | 130-260 万 |
| 硅谷 L7+ / 12 年+ | T10 | 140-230 万 | 100-250 万 | 240-480 万 |

京东已上市，但股价近年承压，RSU 上行空间有限。海归议价空间中等。

### 工作体感

- **优点**：供应链物流技术国内第一、WLB 较好、已上市、北京有房补。
- **缺点**：技术品牌弱、增长承压、AI 投入不激进、亦庄地点远。
- **适合**：做供应链 / 物流 / 运筹 / 机器人、重视 WLB、不追求技术品牌的人。

## 3.4　百度：AI 老牌、自动驾驶第一，但整体在收缩的一个

### 业务与组织基因

百度是**搜索 + AI + 自动驾驶**的老牌。基因：

- **AI 老牌**：吴恩达、陆奇时代打下的 AI 基因，文心一言是国内最早的大模型之一。
- **Apollo 自动驾驶**：国内最早且仍领先的 L4 自动驾驶，萝卜快跑在武汉 / 北京运营。
- **整体收缩**：搜索被字节分流、移动生态承压，近年裁员多，但 AI / 智驾仍投入。

### 海归偏好与岗位

- **Apollo 自动驾驶**：感知 / 规控 / 地图 / 仿真，对硅谷做 AV 的人极友好，国内最成熟的 AV 团队之一。
- **文心 / 大模型**：ERNIE、文心一言，对硅谷 NLP / 大模型训练的人有需求。
- **搜索 / 推荐**：老底盘，对硅谷做 search 的人友好，但 HC 紧。
- **小度 / 智能设备**：语音 / 多模态，对硅谷做语音 / 边缘 AI 的人友好。

**劝退点**：百度整体在收缩，非 AI / 非智驾业务 HC 紧、裁员风险高。北京西二旗地点一般。技术品牌力在下降，年轻人才流失严重。

### 薪酬与级别

百度职级 T3-T11（参考阿里体系），海归常见落点：

| 海归背景 | 百度职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | T6 / T7 | 50-80 万 | 15-30 万 | 65-110 万 |
| 硅谷 L6 / 8 年 | T8 / T9 | 80-140 万 | 40-100 万 | 120-240 万 |
| 硅谷 L7+ / 12 年+ | T10 | 140-220 万 | 80-200 万 | 220-420 万 |

百度已上市，但股价长期承压，RSU 上行有限。海归议价空间在 AI / 智驾方向较大。

### 工作体感

- **优点**：AI / 智驾技术国内顶级、WLB 较好、技术文化好、已上市。
- **缺点**：整体收缩、非 AI 业务裁员风险、技术品牌力下降、年轻人才流失。
- **适合**：做自动驾驶 / AI / NLP、重视技术深度、能接受公司整体承压的人。

## 3.5　小米：IoT 硬件第一，造车新势力之一

### 业务与组织基因

小米是**手机 + IoT + 互联网服务 + 造车**的硬件公司。基因：

- **硬件基因**：手机 / 智能家居 / 米家生态，硬件 + 软件一体化。
- **小米汽车**：SU7 成功后，造车成为第二曲线，对汽车工程师需求猛增。
- **性价比文化**：成本控制极严，反映在薪酬上偏保守。

### 海归偏好与岗位

- **小米汽车**：三电 / 智驾 / 座舱 / 制造，对硅谷做 EV / AV 的人极友好，2024-2026 大规模招人。
- **手机 / IoT 硬件**：SoC、影像、音频、连接，对硅谷做硬件 / 驱动的人友好。
- **澎湃 OS / 互联网服务**：对硅谷做 OS / 移动互联网的人有需求。
- **小米 AI / 大模型**：自研大模型规模小，但对端侧 AI 有需求。

**劝退点**：小米薪酬在五家中偏保守，性价比文化意味着不会为海归开天价。北京小米科技园地点好但亦庄工厂远。

### 薪酬与级别

小米职级 13-22（参考华为体系），海归常见落点：

| 海归背景 | 小米职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | 16 / 17 | 50-75 万 | 15-30 万 | 65-105 万 |
| 硅谷 L6 / 8 年 | 18 / 19 | 75-130 万 | 40-100 万 | 115-230 万 |
| 硅谷 L7+ / 12 年+ | 20 / 21 | 130-200 万 | 80-200 万 | 210-400 万 |

小米已上市，造车业务带动股价回升，RSU 有一定上行。海归议价空间在汽车方向大。

### 工作体感

- **优点**：IoT / 造车赛道、硬件 + 软件一体化、WLB 较好、北京地点好、已上市。
- **缺点**：薪酬保守、AI 投入小、性价比文化议价难。
- **适合**：做硬件 / 汽车 / IoT、重视 WLB、不追求最高薪的人。

## 3.6　网易：游戏第一梯队、WLB 最好、最被低估的一个

### 业务与组织基因

网易是**游戏 + 音乐 + 教育 + 电商（严选）**的"佛系"大厂。基因：

- **游戏为主**：梦幻西游、阴阳师、永劫无间、蛋仔派对，游戏收入国内第二（仅次于腾讯）。
- **佛系文化**：网易是所有大厂里 WLB 最好的之一，965 在很多团队是常态。
- **技术被严重低估**：网易的游戏引擎、自研 ML、云信 / 七鱼音视频，技术含量高但外界不感知。

### 海归偏好与岗位

- **游戏技术**：自研引擎、图形学、AI NPC、反外挂，对硅谷做 graphics / game engine 的人极友好。
- **云音乐 / 推荐算法**：音乐推荐、内容理解，对硅谷做 recommendation 的人友好。
- **有道 / 教育 AI**：教育大模型、子曰，对硅谷做 EdTech AI 的人友好。
- **严选 / 电商**：to C 电商，对硅谷做电商的人有需求但 HC 小。

**劝退点**：网易整体规模小、AI 投入不激进、杭州 / 广州双总部。游戏业务对非游戏背景的人门槛高。

### 薪酬与级别

网易职级参考阿里体系，海归常见落点：

| 海归背景 | 网易职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | P6 / P7 | 50-75 万 | 10-25 万 | 60-100 万 |
| 硅谷 L6 / 8 年 | P7 / P8 | 75-130 万 | 30-80 万 | 105-210 万 |
| 硅谷 L7+ / 12 年+ | P8 / P9 | 130-200 万 | 60-150 万 | 190-350 万 |

网易已上市，薪酬在五家中最低，但 WLB 最好。海归议价空间中等。

### 工作体感

- **优点**：WLB 五家最好、游戏技术国内顶级、杭州 / 广州宜居、已上市、文化温和。
- **缺点**：薪酬最低、规模小、AI 投入小、非游戏方向机会少。
- **适合**：做游戏 / 图形、极致重视 WLB、可接受薪酬不顶配的人。

- 做**本地生活 / 调度 / LBS** → 美团几乎唯一选。

- 做**AI / 大模型** → 百度文心（在第二梯队内），但更建议去第一梯队或第 05 章独角兽。
- 重视**极致 WLB** → 网易优先，京东 / 小米次之。

## 3.8　一个常被问的问题：第二梯队会不会"掉队"

很多人担心第二梯队长期会被第一梯队 + AI 独角兽吃掉。本书的判断：

- **百度**：长期承压是事实，但 Apollo + 文心的技术壁垒仍在，5 年内不会掉出第二梯队。
- **京东 / 美团**：各自垂直赛道壁垒深，本地生活 / 供应链是重资产护城河，5-10 年稳。
- **小米**：造车成功后进入新增长曲线，IoT 生态壁垒深，5-10 年稳。
- **网易**：游戏现金流稳，佛系但不会掉队，规模小是结构性事实。

**第二梯队不是"过渡态"，是"差异化生存态"**。对海归，它们提供的是第一梯队给不了的 WLB + 特定赛道深度 + 议价空间。

## 本章小结

- 第二梯队五家各有第一赛道：美团本地生活、京东供应链、百度智驾、小米 IoT/造车、网易游戏。
- WLB 普遍好于第一梯队，equity 全部已上市可变现。
- 海归议价空间反而大，因为海归在第二梯队稀缺。
- AI 投入除百度外都不激进，纯 AI 方向建议去第一梯队或独角兽。
- 第二梯队是"性价比选"，适合追求 WLB / 特定赛道 / 议价空间的海归。
