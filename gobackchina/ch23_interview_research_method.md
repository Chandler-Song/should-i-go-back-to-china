# 第 23 章　访谈调研方法与问题清单

> 公开信息 + 人脉只能给"中观"认知，"微观"（真实团队 / 文化 / leader）需通过访谈。本章给你一套访谈方法 + 问题清单。

> ⚠️ **本章数字声明**：本章访谈案例中出现的薪酬/总包等具体数字，均为化名 + 脱敏处理的综合估算，**并非真实个人薪酬，也不代表任何公司官方标准**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

---

## 23.1　访谈调研的价值与边界

### 价值

- **一手信息**：公开信息滞后 + 包装，访谈给一手。
- **微观认知**：团队 / leader / 文化 / 真实薪酬，公开信息难覆盖。
- **反确认**：访谈可验证 / 反驳公开信息。
- **关系建立**：访谈本身建人脉。

### 边界

- **样本偏差**：访谈对象可能不代表性。
- **主观偏差**：访谈对象有个人情绪 / 利益。
- **信息敏感**：部分信息（薪酬 / 裁员）敏感，难直问。
- **建议**：访谈 3-5 人交叉，不依赖单一。

## 23.2　访谈对象的选择

### 理想访谈对象

1. **在目标公司 / 团队工作的前同事 / 朋友**：最可信 + 最深度。
2. **近期离职的人**：无利益 + 敢说真话。
3. **海归同温层**：理解你的背景 + 关注点。
4. **不同级别 / 职能**：leader 给战略视角，IC 给执行视角，HR 给流程视角。
5. **不同时间段入职**：老员工给历史，新员工给近期。

### 避免的访谈对象

- **纯营销 / 猎头**：利益相关，信息偏。
- **情绪化离职者**：全负面，不客观。
- **完全不相关的人**：信息不适用。

### 样本量

- 每个目标公司 / 团队：3-5 人，不同角度交叉。
- 总访谈：10-20 人，覆盖目标公司 + 赛道 + 城市。

## 23.3　访谈的请求与安排

### 请求

- **关系到位**：先有关系再访谈，不要冷请求。
- **明确目的**：说明是回国调研，求信息，不是求职。
- **尊重时间**：请求 30-45 分钟，不超 1 小时。
- **形式**：视频 / 电话 / 面谈，按对方便利。
- **话术**："我正在认真评估回国，希望了解贵司 X 团队的真实情况，能否 30 分钟访谈？纯调研不求职，感谢！"

### 安排

- **发日历邀请**：正式 + 明确时间。
- **提前发问题大纲**：让对方准备，不冷访。
- **准时**：尊重对方时间。
- **感谢**：访谈后感谢 + 保持关系。

## 23.4　访谈问题清单：公司 / 团队 / 岗位

### 公司层面

1. 公司近 1-2 年业务 / 组织有什么大变化？
2. 公司现在整体在扩张 / 收缩 / 调整？哪些方向加码 / 砍？
3. 公司文化真实如何（加班 / 政治 / 晋升 / WLB）？
4. 公司海归友好度如何？海归多吗？适应如何？
5. 公司近期有裁员 / 优化吗？哪些团队受影响？
6. 公司长期前景你怎么看？IPO / 增长 / 风险？

### 团队层面

7. 团队规模 / 结构 / 平均年龄？
8. 团队做的事在公司战略中位置（核心 / 边缘）？
9. 团队 leader 风格如何（技术 / 管理 / 政治）？
10. 团队文化如何（协作 / 内卷 / 政治）？
11. 团队近 1-2 年人员流动如何（入职 / 离职率）？
12. 团队资源如何（算力 / HC / 预算）？

### 岗位层面

13. 我目标的级别（如 5-1）在团队中是什么位置？
14. 该级别薪酬水位（现金 + 股权）真实如何？
15. 该级别晋升路径 / 通过率如何？
16. 该级别绩效分布 / 考核压力如何？
17. 团队目前招什么方向 / 级别？HC 多少？
18. 如果我入职，可能做什么具体方向？

### 个人层面

19. 你在公司的真实体验如何？满意 / 不满意什么？
20. 如果重新选择，你还会来吗？为什么？
21. 你对海归回国有什么建议 / 警告？
22. 你知道哪些回国成功 / 失败案例？

### 反确认

23. 公开信息说 X（如"字节 5-1 总包 300 万"），真实如何？
24. 我听到的负面（如"X 团队卷 / 裁员"），真实如何？

## 23.5　访谈的技巧

### 问真实，不问包装

- **避免**："你们公司文化好吗？"（包装回答）。
- **改问**："你们团队上周加班到几点？最近一次周末加班是什么时候？"（具体真实）。

### 问具体，不问模糊

- **避免**："薪酬高吗？"（模糊）。
- **改问**："5-1 现金 base 大概多少？期权 grant 中位多少？"（具体）。

### 问行为，不问态度

- **避免**："leader 好吗？"（态度）。
- **改问**："leader 上次 1 on 1 跟你聊了什么？最近一次决策他怎么做的？"（行为）。

### 问反例

- **不只问正面**："成功案例？"
- **也问反例**："你见过哪些不适应 / 离职的？什么原因？"

### 敏感问题委婉

- 薪酬 / 裁员 / 政治敏感，委婉问：
- "5-1 总包区间大概多少？我了解下做参考。"
- "近期有听说优化吗？哪些团队？"
- "团队政治如何？晋升公平吗？"

### 倾听 > 说

- 访谈是听对方，不是说你自己。
- 80% 倾听，20% 提问。
- 不要打断 + 不要急于分享你的情况。

## 23.6　访谈的记录与整理

### 记录

- **征得同意**后录音（便于整理）。
- 或现场笔记（关键词 + 数字 + 案例）。
- 不要靠记忆，访谈信息量大易忘。

### 整理

- 访谈后 24 小时内整理，趁记忆新。
- 按公司 / 团队 / 岗位 / 文化 / 风险分类。
- 标注信息置信度（高 / 中 / 低）+ 来源。
- 存 Notion / 文档，便于决策时查。

### 交叉

- 多个访谈交叉验证，找共识 + 分歧。
- 共识 → 高置信。
- 分歧 → 需深挖或接受不确定。

## 23.7　访谈的伦理

- **保密**：访谈信息不要泄露给第三方，尤其敏感。
- **不利用**：访谈信息不要用于内斗 / 谈判筹码（不道德 + 损关系）。
- **感谢**：访谈后感谢 + 礼物（咖啡 / 饭局 / 互惠）。
- **回报**：未来对方需要时回报，互惠长期。

## 23.8　访谈的"反访谈"

除了你访谈别人，也接受别人访谈你：

- **硅谷同行**：在硅谷的同行想了解国内，你可分享。
- **国内朋友**：国内朋友想了解硅谷，你可分享。
- **互惠**：反访谈是互惠，建人脉 + 信息交换。

## 23.9　一个完整访谈案例

**目标**：了解字节豆包大模型团队。

**访谈对象**：

1. 在豆包的前同事（IC，2 年）。
2. 近期离职豆包的朋友（1 年离职）。
3. 豆包 leader 的 LinkedIn 联系人（间接）。
4. 海归群中在豆包的海归（2 人）。

**访谈**（每人 30-45 分钟）：

- 用第 23.4 章问题清单，公司 / 团队 / 岗位 / 个人 / 反确认全覆盖。
- 记录 + 整理 + 交叉。

**交叉发现**：

- 共识：豆包资源足 + 算理扁平 + 强度高。
- 分歧：晋升通过率（一人说高，一人说低）→ 需深挖。
- 反确认：公开说 5-1 总包 300 万，访谈确认 250-350 万，置信高。

**输出**：豆包团队决策就绪信息包。

## 本章小结

- 访谈给一手微观信息，是公开信息 + 人脉的补充。
- 访谈对象 3-5 人交叉，避免单一偏差。
- 请求要关系到位 + 明确目的 + 尊重时间。
- 问题清单覆盖公司 / 团队 / 岗位 / 个人 / 反确认。
- 技巧：问真实不问包装、问具体不问模糊、问行为不问态度、问反例、敏感委婉、倾听 > 说。
- 记录 + 整理 + 交叉，24 小时内整理。
- 伦理：保密 + 不利用 + 感谢 + 回报。
- 反访谈互惠建人脉。
