# 第 22 章　人脉网络与内推策略

> 回国求职中，**内推 > 猎头 > 海投**，而内推依赖人脉。本章讲如何在回国前 6-12 月系统化重建国内人脉网络。

---

## 22.1　为什么人脉是回国求职的第一资源

国内求职市场的真实排序：

1. **内推（熟人 / 朋友 / 前同事）**：响应率 50-80%，面试率高，议价空间大。
2. **猎头**：响应率 30-50%，专业但代表公司利益。
3. **海投（官网 / Boss 直聘）**：响应率 5-15%，海归高级岗几乎无效。

**对海归高级岗（P7+ / 5-1+），海投几乎无效，必须走内推或猎头**。而内推的质量取决于你在国内的人脉网络。

## 22.2　人脉网络的五层结构

1. **核心层**：前同事 / 同学 / 朋友，深度关系，可内推 + 背书。
2. **次核层**：行业熟人 / 会议认识，中度关系，可内推。
3. **弱连接**：LinkedIn / 微信好友，弱关系，可信息 + 偶尔内推。
4. **海归圈**：海归同温层，理解你的背景，高价值。
5. **影响者**：行业 KOL / 大牛，不直接内推但影响力。

**目标**：回国前建立 20-50 人的有效人脉（核心 5-10 + 次核 10-20 + 弱连接 20-50）。

## 22.3　回国前 6-12 月的人脉建设

### 策略一：激活旧人脉

- **前同事 / 同学**：LinkedIn / 微信联系，更新近况，表达回国意向。
- **国内朋友**：微信保持联系，回国前主动沟通。
- **校友**：校友会 / 校友群，清华 / 北大 / 复旦 / 上交 / 浙大 / 中科大等校友网络强。
- **建议**：列出所有在国内科技圈的旧人脉，逐一激活。

### 策略二：建新人脉

- **行业会议**：回国参加 1-2 个行业会议（QCon / ArchSummit / AICon / GOTC），认识人。
- **线上社区**：知乎 / 小红书 / B 站 / GitHub 活跃，建立可见度。
- **海归社群**：加海归微信群（公司群 / 城市群 / 校友群）。
- **LinkedIn**：主动 connect 国内同行业人，附个性化消息。
- **建议**：每月新增 5-10 有效人脉。

### 策略三：建立可见度

- **技术博客 / 公众号**：写技术文章，建立专业可见度。
- **开源贡献**：参与国内开源项目（PaddlePaddle / MindSpore / Qwen 等）。
- **会议演讲**：在行业会议演讲，建立影响力。
- **建议**：建立可见度让人找你，不只你找人。

### 策略四：互惠原则

- **先给后取**：先帮人（信息 / 介绍 / 资源），再求帮。
- **不要纯索取**：纯索取的人脉不持久。
- **建议**：主动帮人 + 分享信息，建立互惠。

## 22.4　内推的实操

### 找内推人

- 目标公司 → 找在该公司的前同事 / 朋友 / 校友 / 海归圈人。
- 如果没有直接人，找 2 度人（朋友的朋友）请介绍。
- LinkedIn 搜目标公司员工，找共同联系人。

### 内推请求

- **明确**：目标岗位 / 级别 / 你的背景，让内推人好推。
- **简短**：不要长邮件，1 段说清。
- **附简历**：附更新简历（第 37 章）。
- **感谢**：无论结果，感谢内推人。
- **话术**："我在 Google L6 做大模型训练，希望回国加入贵司 X 团队，看到 Y 岗位，能否帮我内推？附简历。感谢！"

### 内推的跟进

- 内推后 1-2 周跟进 HR 状态。
- 如果面试，及时同步内推人。
- 如果 offer，感谢内推人 + 可能请内推人帮谈（内推人对团队了解）。
- 如果拒，感谢 + 保持关系。

## 22.5　内推的"内推费"

部分公司有内推费（成功入职给内推人 5000-30000），这是正常机制：

- **对你**：不影响你，公司付。
- **对内推人**：激励内推。
- **注意**：不要因内推费怀疑内推人动机，正常机制。

## 22.6　人脉的"质量 > 数量"

500 个 LinkedIn 联系人不如 20 个深度关系。**质量 > 数量**：

- **深度关系**：前同事 / 同学 / 朋友，可内推 + 背书 + 深度信息。
- **中度关系**：行业熟人，可内推 + 信息。
- **弱连接**：弱关系，仅信息。

**建议**：优先深化 20-30 个深度 / 中度关系，不追求 500+ 弱连接。

## 22.7　人脉的"互惠"维护

人脉需长期维护，不是用时不维护：

- **定期联系**：核心层月联系，次核层季联系，弱连接年联系。
- **互惠**：主动帮人 + 分享信息 + 介绍人。
- **节日 / 里程碑**：节日问候 + 升职 / 跳槽祝贺。
- **回国后**：落地后人脉维护更需主动（饭局 / 活动 / 帮人）。

## 22.8　海归圈的特别价值

海归圈对回国海归有特别价值：

- **同温层**：理解你的背景 + 挑战，共鸣高。
- **信息**：海归 offer / 公司 / 城市的一手信息。
- **内推**：海归圈内推意愿高（同温层互助）。
- **心理支持**：回国适应期，海归圈心理支持。

**建议**：主动加海归社群（公司海归群 / 城市海归群 / 校友海归群），积极参与。

## 22.9　人脉的"反人脉"

有些"人脉"是负资产：

- **纯索取型**：只求帮不互惠，消耗你。
- **负面型**：负面 / 抱怨 / 情绪化，影响你判断。
- **不诚信型**：信息不实 / 承诺不兑现，损害你。
- **建议**：识别 + 疏远反人脉，不浪费时间。

## 22.10　人脉建设的常见坑

### 坑一：用人时才建

回国前不建人脉，落地后用时方恨少。**回国前 6-12 月开始建**。

### 坑二：只建不维

建了人脉不维护，用时已冷。**定期联系 + 互惠**。

### 坑三：纯索取

只求内推 / 信息不互惠，人脉不持久。**先给后取**。

### 坑四：忽视海归圈

只建国内本地人脉，忽视海归圈，失去同温层支持。**海归圈优先**。

### 坑五：过度依赖单一

只依赖 1-2 个人脉，风险高（人走 / 关系冷）。**分散 20-30 个**。

## 22.11　一个完整人脉建设案例

**背景**：海归 L6 / 在硅谷 8 年 / 目标字节 / 回国前 12 月。

**第 1-3 月（激活旧人脉）**：

- 列出在国内科技圈的旧人脉（前同事 5 / 同学 10 / 校友 15）。
- LinkedIn / 微信逐一激活，更新近况，表达回国意向。
- 结果：激活 20 有效人脉，其中 3 在字节。

**第 4-6 月（建新人脉）**：

- LinkedIn 主动 connect 国内 AI 圈 30 人，附个性化消息。
- 加海归微信群（字节海归群 / 杭州海归群 / 校友海归群）。
- 知乎 / 公众号写 2 篇技术文章，建立可见度。
- 结果：新增 30 有效人脉，其中 5 在字节。

**第 7-9 月（深化 + 互惠）**：

- 与字节 8 人深度交流（信息 + 互惠）。
- 帮 3 人内推硅谷岗位（互惠）。
- 回国参加 1 次行业会议，认识 10 人。
- 结果：字节深度人脉 8 人。

**第 10-12 月（内推 + 求职）**：

- 通过字节深度人脉内推 3 个岗位。
- 拿到 2 个面试，1 个 offer。
- 感谢内推人 + 保持关系。

**结果**：12 月建立 50+ 有效人脉，通过内推拿到 offer。

## 本章小结

- 内推 > 猎头 > 海投，海归高级岗必须内推或猎头。
- 人脉五层：核心 / 次核 / 弱连接 / 海归圈 / 影响者，目标 20-50 有效。
- 回国前 6-12 月建人脉：激活旧 + 建新 + 建可见度 + 互惠。
- 内推实操：明确 + 简短 + 附简历 + 感谢 + 跟进。
- 质量 > 数量，20 深度关系胜 500 弱连接。
- 互惠维护：定期联系 + 互惠 + 节日 + 落地后主动。
- 海归圈同温层价值高，优先参与。
- 反人脉识别 + 疏远。
- 五个坑：用时才建、只建不维、纯索取、忽视海归圈、过度单一。
