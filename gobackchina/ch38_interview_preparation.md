# 第 38 章　面试准备与反面试

> 国内面试与硅谷风格不同。本章讲技术 + 系统 + 行为 + 国内特色的准备，以及"反面试"（你问面试官）。

---

## 38.1　国内面试流程

典型国内大厂面试 4-6 轮：

1. **HR 初筛**（30 分钟）：背景 + 期望 + 流程。
2. **技术面 1-3**（每 60 分钟）：算法 + 系统 + 项目。
3. **交叉面 / 加面**（60 分钟）：跨团队 / 更高级别。
4. **hiring manager 面**（60 分钟）：行为 + 团队 fit + 期望。
5. **VP 面**（高级岗，30 分钟）：战略 + 文化。
6. **HR 谈 offer**：薪酬 + 入职。

**周期**：4-8 周，多流程并行。

## 38.2　技术面准备

### 算法

- **难度**：LeetCode 中-难，国内大厂算法权重高于硅谷。
- **准备**：刷 LeetCode 200-400 题，重点中-难 + 高频。
- **风格**：国内面试常要求**手写代码**（在线编辑器或纸），不只口述。
- **时间**：每题 30-45 分钟，需快 + 准。
- **建议**：每日 1-2 题，6-12 周准备。

### 系统

- **难度**：国内系统设计权重上升，尤其高级岗。
- **准备**：DDIA + Google papers + 系统设计书 + 模拟。
- **风格**：国内系统设计常结合**业务场景**（电商 / 社交 / 推荐 / 大模型），需业务理解。
- **建议**：练 10-20 个系统设计题，覆盖不同场景。

### 项目深挖

- **风格**：国内面试深挖项目（技术 + 业务 + 角色 + 影响 + 权衡），比硅谷更深。
- **准备**：每核心项目准备 5-10 分钟讲清 + 深挖问题。
- **建议**：列出核心项目 + 深挖问题 + 答案。

### 技术栈

- **风格**：国内面试问技术栈细节（框架 / 工具 / 原理），不只用法。
- **准备**：你简历上每个技术栈，准备原理 + 优化 + 对比。
- **建议**：不要写不熟的技术栈，写了就要能深答。

## 38.3　系统设计准备

### 国内常考系统设计

- **电商**：商品 / 订单 / 库存 / 支付 / 推荐。
- **社交**：feed / 消息 / 关系 / 推送。
- **推荐 / 广告**：召回 / 排序 / 竞价 / 投放。
- **大模型**：训练 infra / 推理 serving / RAG / agent。
- **基础设施**：存储 / 计算 / 网络 / 数据。
- **视频 / 直播**：转码 / CDN / 推流。

### 准备方法

1. **学**：DDIA + Google papers + 系统设计书。
2. **练**：每类练 1-2 个，画图 + 讲清。
3. **业务**：理解国内业务场景 + 规模 + 挑战。
4. **权衡**：每设计讲权衡（CAP / 一致性 / 成本 / 性能）。
5. **模拟**：与朋友 / 猎头模拟 5-10 次。

### 系统设计框架

- **需求**：功能 + 非功能 + 规模。
- **估算**：QPS / 存储 / 带宽。
- **API**：接口设计。
- **数据模型**：存储 + schema。
- **架构**：组件 + 数据流。
- **扩展**：分片 / 缓存 / 异步。
- **容错**：故障 + 恢复。
- **权衡**：每决策的权衡。

## 38.4　行为面准备

### 国内行为面特色

- **项目深挖**：技术 + 业务 + 角色 + 冲突 + 结果。
- **文化 fit**：加班 / 协作 / 价值观（阿里价值观考核真实）。
- **动机**：为什么回国 / 为什么这公司 / 长期规划。
- **期望**：级别 / 薪酬 / 团队 / 方向期望。

### 准备方法

- **STAR**：每核心经历准备 STAR（情境 / 任务 / 行动 / 结果）。
- **回国故事**：准备 3-5 分钟讲清为什么回国 + 为什么这公司。
- **冲突 / 失败**：准备 2-3 个冲突 / 失败 + 学习。
- **问题**：准备问面试官的问题（下节）。

### 常见行为问题

- 为什么回国？为什么现在？为什么我们？
- 你最大的成就 / 失败？学到了什么？
- 你与领导 / 同事冲突？怎么处理？
- 你带过人吗？怎么带？怎么培养？
- 你加班怎么看？（国内常问）
- 你 5 年规划？
- 你期望级别 / 薪酬？（谨慎答，第 11 章）

## 38.5　国内特色准备

### 业务理解

- 国内面试重视业务理解，不只技术。
- 准备：目标公司业务 + 行业 + 规模 + 挑战。
- 例：面字节，了解抖音 / 豆包 / 推荐业务。

### 文化适配

- 国内面试评估文化 fit（加班 / 协作 / 价值观）。
- 准备：了解目标公司文化（第 02-04 章）+ 真实表达适配。
- 不要假装，但表达愿意适配。

### 中文表达

- 国内面试中文，技术术语可英文。
- 准备：技术概念中文表达 + 模拟中文面试。
- 海归常见问题：中文技术表达生疏，需练。

### 手写代码

- 国内常要求手写（在线编辑器或纸），不只口述。
- 准备：练手写 + 边写边讲。

### 八股文

- 国内部分公司有"八股文"（固定技术问题），如 JVM / MySQL / Redis 原理。
- 准备：了解目标公司八股 + 准备。
- 不要轻视，国内常考。

## 38.6　反面试：你问面试官

面试是双向，你也要问面试官。好问题展示思考 + 帮你判断。

### 问团队 / 角色

- 团队规模 / 结构 / 平均年龄？
- 我将做什么具体方向？
- 团队在公司的战略位置？
- 团队近 1-2 年人员流动？

### 问技术 / 资源

- 技术栈 / 架构 / 规模？
- 算力 / HC / 预算？
- 技术债 / 重构空间？

### 问 leader / 文化

- leader 风格？（如面 hiring manager 直接问）
- 团队文化（协作 / 内卷 / 政治）？
- 晋升路径 / 通过率？
- 加班 / WLB 真实？

### 问期望 / 反馈

- 你对我这轮的反馈？
- 接下来流程 / 时间？
- 有什么顾虑我可以 address？

### 反面试的目的

- **判断**：判断团队 / 文化 / 资源 / 期望。
- **展示**：展示思考 + 关注。
- **建立**：与面试官建立对话。

**建议**：每轮准备 3-5 个问题，不只最后问。

## 38.7　面试的"反套路"

识别面试官套路 + 应对：

### 套路一：压力面

- 面试官故意施压（质疑 / 打断 / 否定）。
- **应对**：保持冷静 + 不 defensive + 用数据 / 逻辑回应。

### 套路二：模糊问题

- 故意问模糊（"设计一个系统"）。
- **应对**：主动澄清需求 + 假设 + 设计。

### 套路三：深挖到底

- 不断深挖一个点直到你不会。
- **应对**：答到你会的 + 不会的诚实说 + 讲你会怎么学。

### 套路四：诱导错误

- 诱导你说错 / 妥协。
- **应对**：坚持正确 + 不为迎合说错。

### 套路五：薪酬试探

- 早问期望薪酬。
- **应对**：第 11 章锚定 + 不早定死。

## 38.8　面试后的跟进

### 感谢

- 每轮后发感谢信（HR + 面试官）。
- 简短 + 专业 + 1-2 句强化。

### 复盘

- 每轮后立即复盘：答好 / 答差 / 改进。
- 调整下一轮策略。

### 跟进

- 1-2 周无反馈，礼貌跟进 HR。

### 多流程

- 多公司并行，不 all-in 一家。
- 用 A 公司 offer 促 B 公司。

## 38.9　面试准备的"时间线"

### T-6 到 T-12 周

- 算法：每日 1-2 题 LeetCode。
- 系统：DDIA + 练 10-20 题。
- 项目：列核心 + 深挖准备。

### T-3 到 T-6 周

- 模拟面试 3-5 次。
- 行为 + 回国故事准备。
- 国内特色（业务 / 文化 / 八股）准备。

### T-1 到 T-3 周

- 简历投递 + 面试开始。
- 每面试后复盘 + 调整。
- 多流程并行。

### T-0 到 T-1 周

- 最终模拟 + 心理准备。
- 睡眠 + 状态调整。

## 38.10　一个完整面试准备案例

**背景**：海归 L6 / 做大模型训练 / 目标字节豆包 5-1。

**准备**（8 周）：

- **算法**（6 周）：LeetCode 200 题，中-难 + 高频，每日 1-2 题。
- **系统**（4 周）：DDIA + 练 15 题，重点大模型训练 infra / 推荐 / 分布式。
- **项目**（2 周）：Gemini 训练 infra + 分布式训练，深挖准备。
- **行为**（2 周）：STAR 5 个 + 回国故事 + 冲突 / 失败。
- **国内特色**（2 周）：字节业务（抖音 / 豆包）+ 文化 + 中文表达 + 手写。
- **模拟**（2 周）：与朋友 / 猎头模拟 5 次。
- **反面试**：准备 10 个问题（团队 / 技术 / 文化 / 期望）。

**面试**（4 周）：

- HR 初筛 → 技术 3 轮 → 交叉 → hiring manager → VP。
- 每轮复盘 + 调整。
- 多流程（字节 + 阿里 + 智谱）并行。

**结果**：拿到字节 5-1 offer + 阿里 P8 offer，多 offer 议价。

## 本章小结

- 国内面试 4-6 轮，4-8 周，算法权重高于硅谷。
- 技术面：算法（手写）+ 系统（业务场景）+ 项目深挖 + 技术栈。
- 系统设计：电商 / 社交 / 推荐 / 大模型 / infra，框架 + 权衡。
- 行为面：STAR + 回国故事 + 文化 fit + 期望。
- 国内特色：业务理解 + 文化 + 中文 + 手写 + 八股。
- 反面试：问团队 / 技术 / 文化 / 期望，判断 + 展示 + 建立。
- 反套路：压力 / 模糊 / 深挖 / 诱导 / 薪酬试探。
- 面试后：感谢 + 复盘 + 跟进 + 多流程。
- 8 周准备：算法 + 系统 + 项目 + 行为 + 国内特色 + 模拟。
