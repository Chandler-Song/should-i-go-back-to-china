# 第 29 章　回国时机选择的多因素模型

> "什么时候回国"和"要不要回国"同样重要。时机影响薪酬水位 30%+、晋升概率、家属适应、长期空间。本章建一个多因素时机模型。

---

## 29.1　时机的五个关键变量

1. **年龄 / 职级窗口**：35 / 40 / 45 是国内大厂年龄节点。
2. **行业周期窗口**：AI / 芯片 / 出海的扩张 / 收缩周期。
3. **公司融资窗口**：创业公司融资后 6 个月是招人窗口。
4. **个人身份窗口**：绿卡 / 485 / H1B 进度影响可逆性。
5. **家属窗口**：子女年龄 / 配偶职业 / 父母健康。

**最优时机 = 五变量同时 favorable**，但通常不会全 favorable，需权衡。

## 29.2　年龄 / 职级窗口

### 国内大厂年龄节点

- **30 岁前**：黄金窗口，P7 起步，晋升空间大，年龄焦虑低。
- **30-35**：主流窗口，P7-P8，晋升仍可，年龄焦虑开始。
- **35-40**：收窄窗口，P8 主流，P9 难，年龄焦虑上升。
- **40-45**：窄窗口，P8+ / 专家线 / 管理线，generalist 难。
- **45+**：很窄，几乎只专家 / 管理 / 创业 / 高校。

### 年龄对海归的影响

- **30 岁前回国**：最优，议价 + 晋升 + 适应都好。
- **30-35 回国**：好，主流海归窗口。
- **35-40 回国**：可，但需选对方向 + 级别，避免 generalist。
- **40+ 回国**：需强理由 + 强背景 + 专家 / 管理 / 创业 / 高校路径，generalist 几乎不通。

**建议**：如回国，**35 岁前最优，40 岁前可，45+ 需强理由**。

## 29.3　行业周期窗口

### AI 大模型

- **2023-2025**：扩张高峰，六小虎 + 大厂 lab 疯狂招人，海归溢价高。
- **2026**：开始收缩，部分六小虎裁员，海归溢价降但仍在。
- **2027+**：不确定，可能整合 + 寡头，海归机会减。

**判断**：AI 海归窗口 **2023-2026 最宽，2027+ 收窄**。如做 AI，2025-2026 仍是相对好窗口，但需选对公司。

### 芯片

- **2024-2027**：国产替代 + 大厂自研高峰，海归溢价最高。
- **2028+**：可能整合，但国产替代长期，机会持续。

**判断**：芯片海归窗口 **2024-2027 最宽，长期仍好**。如做芯片，2025-2027 是好窗口。

### 出海

- **2024-2026**：TikTok / Temu / Shein / 游戏 / SaaS 出海高峰，海归价值高。
- **2027+**：地缘政治可能限制，但出海长期趋势。

**判断**：出海海归窗口 **2024-2026 宽**。如做出海，2025-2026 是好窗口。

### 互联网大厂 generalist

- **2022-2026**：降本增效，HC 紧，海归 generalist 机会少。
- **2027+**：可能局部放松，但 generalist 长期不是国家战略。

**判断**：互联网 generalist 海归窗口 **长期窄**，不建议 generalist 海归首选。

### 综合

- **2025-2027**：AI（收窄但仍好）+ 芯片（最宽）+ 出海（宽）综合，是相对好窗口。
- **2028+**：AI 可能整合，芯片仍好，出海受限，窗口收窄。
- **建议**：如回国，**2025-2027 是相对好窗口，2028+ 需更谨慎**。

## 29.4　公司融资窗口（创业公司）

如去创业公司，融资窗口关键：

- **融资后 0-6 月**：招人窗口，HC + 薪酬好，海归议价空间大。
- **融资后 6-12 月**：招人减速，HC 紧，议价空间降。
- **融资后 12+ 月**：如未下一轮，可能裁员，风险高。

**判断**：去创业公司要**踩在融资后 0-6 月**，错过就 either 没名额 or 估值已高 / 风险升。

**实操**：

- 关注目标公司融资动态（IT 桔子 / Crunchbase）。
- 融资后立即联系人 / 投简历。
- 避免融资后 12+ 月未下一轮的公司。

## 29.5　个人身份窗口

### 绿卡

- **H1B 第 1-3 年**：回国放弃 H1B，可逆性低（重签难）。
- **H1B 第 4-6 年**：接近 6 年上限，回国机会成本低。
- **I-140 已批**：PD 排期中，回国放弃排期，重排可能 10+ 年。
- **I-485 已交**：如离美超 1 年需 AP，回国仍可保留。
- **绿卡已批**：可保留（re-entry permit 2 年），回国可逆性高。
- **公民**：回国需签证，但回美无障碍。

**判断**：

- 绿卡已批 → 回国可逆性高，时机灵活。
- I-485 已交 → 回国可逆性中，需 AP 规划。
- I-140 已批 / PD 排期 → 回国放弃排期，机会成本高，需强理由。
- H1B 第 1-3 年 → 回国放弃 H1B，可逆性低，需强理由。

### 在美资产

- **未归属 RSU**：回国后仍 vesting，但需规划税务。
- **401k / 股票**：保留，但需跨境税务规划。
- **房产**：卖 / 租，影响资金 + 长期。

**判断**：在美资产多 → 回国机会成本高，需 sign-on 补偿 + 跨境规划。

## 29.6　家属窗口

### 子女年龄

- **0-5 岁**：最优，学制切换易。
- **6-10 岁**：好，切换可。
- **11-14 岁**：中，国际学校优先。
- **15+**：难，几乎只能国际 / 留美。

**判断**：子女 0-10 回国最优，11-14 可，15+ 难。

### 配偶职业

- **配偶工程岗**：回国可找，窗口灵活。
- **配偶非工程岗**：回国断崖，需配偶愿 + 财务安排。
- **配偶全职**：回国可行，需配偶愿。

### 父母健康

- **父毌健康**：回国不急，可晚。
- **父毌需要照顾**：回国急，但一线 vs 父毌城市距离问题。

## 29.7　时机综合模型

```
时机分 = 年龄窗口分 × 行业周期分 × 公司融资分 × 身份窗口分 × 家属窗口分
```

每分 1-5，乘积高 = 时机好。

**示例一**：35 岁 / AI / 字节（已成熟） / 绿卡已批 / 子女 8 岁：

- 年龄 4 × 行业 4 × 公司 3 × 身份 5 × 家属 4 = 960（满分 3125，相对好）

**示例二**：42 岁 / generalist / 大厂 / H1B 第 3 年 / 子女 16 岁：

- 年龄 2 × 行业 2 × 公司 2 × 身份 2 × 家属 1 = 16（很差）

**判断**：示例一时机好，示例二时机差。

## 29.8　时机的"不可逆"考量

部分时机变量不可逆，需特别慎重：

- **绿卡排期**：放弃后重排可能 10+ 年，近不可逆。
- **子女学制**：15+ 切换极难，近不可逆。
- **年龄**：错过 35 / 40 窗口不可逆。

**建议**：不可逆变量权重高，决策需特别慎重。

## 29.9　时机的"可逆"考量

部分变量可逆，降低决策风险：

- **工作**：回国 2-3 年可返美。
- **城市**：回国后可迁城。
- **公司**：回国后可跳槽。

**建议**：可逆变量不需过度纠结，决策后可调整。

## 29.10　时机的"等待 vs 行动"决策

很多人纠结"现在回 vs 再等"。本书判断：

### 倾向现在回的情况

- 年龄接近 35 / 40 窗口尾，再等错过。
- 行业周期在高峰，再等收窄。
- 公司融资后 0-6 月窗口。
- 家属子女年龄正好，再等难。
- 绿卡已批，可逆性高。

### 倾向再等的情况

- 年龄仍轻（30 以下），窗口宽。
- 行业周期在收缩，再等可能反弹。
- 公司融资后 12+ 月，等下一轮。
- 家属未同步，再等同步。
- 绿卡未批 / 排期中，再等身份。
- 在美资产未归属多，再等归属。

**建议**：列你的五变量状态，倾向现在回 / 再等，不模糊。

## 29.11　一个完整时机决策案例

**背景**：海归 L6 / 34 岁 / 在美 8 年 / I-140 已批 PD 排期 2026 / AI 方向 / 已婚一子 6 岁 / 配偶工程岗。

**五变量**：

- 年龄 34：窗口尾，4 分。
- 行业 AI：2026 收窄但仍好，3 分。
- 公司：目标字节豆包 / 智谱，融资成熟，3 分。
- 身份：I-140 已批 PD 2026，回国放弃排期，2 分（机会成本高）。
- 家属：子女 6 岁好，配偶工程岗好，4 分。

**时机分**：4 × 3 × 3 × 2 × 4 = 288（中上）。

**分析**：

- 年龄 + 行业 + 家属 favorable，催现在回。
- 身份 unfavorable（放弃排期），催再等。
- 权衡：年龄窗口尾（再等错过 35）vs 身份（再等 2 年拿绿卡）。

**决策**：

- 如年龄优先（35 前回）→ 现在回，放弃排期，接受机会成本。
- 如身份优先（拿绿卡）→ 再等 2 年，但 36 岁回，年龄窗口窄。
- **综合**：年龄窗口近不可逆，身份可补（sign-on + 长期），倾向现在回。

**结论**：34 岁现在回，时机分中上，年龄 + 行业 + 家属 favorable 盖身份 unfavorable。

---

## 本章小结

- 时机五变量：年龄 / 职级、行业周期、公司融资、个人身份、家属。
- 年龄：35 前最优，40 前可，45+ 需强理由。
- 行业：AI 2023-2026 宽 2027+ 窄，芯片 2024-2027 最宽，出海 2024-2026 宽。
- 创业公司：踩融资后 0-6 月。
- 身份：绿卡已批可逆性高，排期中机会成本高。
- 家属：子女 0-10 最优，15+ 难。
- 时机分 = 五变量乘积，高 = 好。
- 不可逆变量权重高，可逆变量不纠结。
- 倾向现在回 / 再等看五变量状态。
- 2025-2027 综合是相对好窗口。
