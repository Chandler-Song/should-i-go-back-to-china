# 第 15 章　住房与购房决策模型

> 住房是回国后最大单笔支出 + 最难反悔决策。本章给你一套购房决策模型，回答"买不买、什么时候买、买哪里、买多大"。

> ⚠️ **本章数字声明**：本章出现的房价/首付/月供/利率等具体数字，均来源于 2024-2026 年互联网公开信息（链家、贝壳、央行利率公告、媒体报道等）的综合估算，**并非官方数据，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

---

## 15.1　回国住房的三个核心问题

1. **买不买**：回国是否立刻买房，还是先租一年观察。
2. **买哪里**：城市内区位选择，影响通勤 + 学区 + 升值。
3. **买多大 + 什么价**：预算 + 杠杆 + 现金流。

**本书的默认建议：回国第一年先租，不立刻买**。原因：

- 回国后你对该城市的真实体感 / 通勤 / 学区 / 房价走势判断不足，立刻买容易踩坑。
- 回国第一年适应期 + 工作压力大，叠加购房决策精力不够。
- 2024-2026 房价整体在调整，不急于一时。
- 租一年后你对城市 + 自己长期是否留 + 家庭需求更清楚。

**例外**：如果配偶强烈要求"有房才安稳" + 你已确定长期留 + 房价回调到位，可考虑买，但仍建议先租 6 个月再决。

## 15.2　买不买：决策树

```
是否确定长期（5+ 年）留该城？
├─ 否 → 不买，租
└─ 是 → 配偶是否强烈要求买？
   ├─ 否 → 是否有投资需求？
   │  ├─ 否 → 租 1-2 年观察
   │  └─ 是 → 谨慎买（投资逻辑）
   └─ 是 → 现金流是否够？
      ├─ 否 → 租 + 攒钱
      └─ 是 → 买（自住逻辑）
```

**关键判断**：

- **自住 vs 投资**：自住看居住需求 + 现金流，投资看租售比 + 升值预期。**不要混**。
- **长期是否留**：如果 5 年内可能迁城 / 回美，买不划算（交易成本 + 流动性锁死）。
- **现金流**：首付 + 月供不能影响生活 + 子女教育 + 应急金。**月供 < 月收入 30%** 是安全线。

## 15.3　买哪里：城市内区位选择

城市内区位选择影响通勤 + 学区 + 升值，比城市选择更细。四个维度：

### 维度一：通勤

- **原则**：通勤单程 < 45 分钟，否则长期幸福度低。
- **选**：地铁沿线 / 公司附近 / 通勤便利区位。
- **避**：远郊 / 通勤 > 1 小时，除非远程 / 弹性。

### 维度二：学区

- **有子女**：学区是核心，公立看学区房 + 户口，国际看国际学校辐射区。
- **无子女 / 子女将读国际**：学区权重低，可买非学区省成本。
- **注意**：学区政策变动（多校划片 / 教育均衡），不要为学区付过高溢价。

### 维度三：升值 / 抗跌

- **核心地段**：北京海淀 / 上海前滩 / 深圳南山 / 杭州未来科技城——抗跌 + 升值。
- **远郊 / 新区**：波动大，2021-2024 远郊回调 30-50%，核心地段回调 15-25%。
- **2026 判断**：核心地段相对稳，远郊风险高，**优先核心地段或成熟次中心**。

### 维度四：生活配套

- 商业 / 医疗 / 教育 / 公园 / 餐饮配套，影响日常幸福。
- **选**：成熟配套区，避纯新区（配套未起来）。

## 15.4　买多大 + 什么价：预算模型

### 预算公式

```
购房预算 = (现金可用 - 应急金 - 子女教育金 - 其他大额) × 杠杆系数
月供 < 月收入 × 30%
```

**示例**：海归高级工程师，现金 300 万，应急金 50 万，子女教育金 100 万，其他 50 万，可用 100 万首付，杠杆 3 倍：

- 购房预算 = 100 万首付 × 3 = 300 万总价
- 月收入 15 万，月供 < 4.5 万，300 万 30 年贷款月供约 1.5 万，安全。

**注意**：

- **不要全押现金**：留应急金 + 教育金，不要 all-in 房产。
- **杠杆适度**：3 倍杠杆（首付 30%）是常规，不要过度杠杆。
- **月供安全线**：< 月收入 30%，留生活 + 教育 + 应急空间。

### 杠杆选择

- **低杠杆（首付 50%+）**：现金流压力小 + 利息少，适合保守。
- **中杠杆（首付 30%）**：常规，平衡。
- **高杠杆（首付 20%）**：现金流压力大 + 利息多，慎选。

### 贷款选择

- **公积金贷款**：利率低（3.1%），额度有限（个人 50-120 万），优先用。
- **商业贷款**：利率高（4.0-4.5%），额度足，补公积金不足。
- **组合贷**：公积金 + 商贷，最优组合。
- **注意**：公积金贷款需连续缴存 6-12 月，回国新缴需等待。

## 15.5　房价走势判断（2024-2026）

本书不预测房价，但给判断框架：

### 一线

- **核心地段**：2021-2024 回调 15-25%，2025-2026 企稳，长期抗跌 + 温和升。
- **远郊 / 新区**：回调 30-50%，2025-2026 仍承压，长期分化。
- **判断**：核心地段可买，远郊慎买。

### 新一线

- **杭州 / 成都 / 合肥核心**：相对稳，回调 10-20%，长期有产业支撑。
- **其他新一线**：分化，看产业 + 人口流入。
- **判断**：产业强 + 人口流入的新一线核心可买。

### 二三线

- 整体承压，人口流出城市慎买。
- **判断**：除非自住 + 长期留，否则慎买。

## 15.6　购房的"海归特殊问题"

### 问题一：户口

- 部分城市购房需户口 / 社保年限（北京 / 上海严，深圳 / 广州松，新一线多数松）。
- **解决**：先了解购房资格，无资格可先租 + 攒资格，或选资格松的城市。

### 问题二：贷款资格

- 回国新缴公积金 / 社保，贷款资格需等待 6-12 月。
- **解决**：先租 + 攒资格，或用商业贷款（资格松）。

### 问题三：跨境资金

- 在美积蓄汇回国内购房，受外汇管制（每人每年 5 万美元额度）。
- **解决**：提前规划 + 合规渠道（亲属额度 + 银行汇款 + 部分情况境外购房），第 40 章详述。

### 问题四：美国房产处置

- 在美房产是否卖 / 租，影响回国购房资金 + 长期规划。
- **解决**：卖（变现 + 简化）/ 租（保留 + 长期）看长期是否回美，第 40 章详述。

### 问题五：配偶是否上产证

- 配偶上产证影响产权 + 未来处置。
- **解决**：通常共同上，但需考虑户口 / 贷款资格 / 未来处置便利。

## 15.7　租房策略：回国第一年

如果按本书建议先租一年，租房策略：

### 选区位

- 先租公司附近 / 通勤便利区，体验城市。
- 不要立刻租学区（子女学校未定），不要立刻租远郊（通勤累）。

### 选户型

- 一家三口 80-120 平两居三居，单身 / 二人 50-80 平一居两居。
- 不要租过大（贵 + 浪费），不要租过小（憋屈）。

### 租金预算

- 月租 < 月收入 25%，留生活 + 储蓄空间。
- **示例**：月收入 15 万，月租 < 3.75 万，可租 2-3 万 / 月的好房。

### 租期

- 先签 1 年，灵活续。
- 避免长租（3+ 年），回国第一年变化多。

## 15.8　购房 vs 租房的长期财务比较

**购房**：

- 优点：资产 + 强制储蓄 + 学区 + 安稳感 + 抗通胀。
- 缺点：首付锁死 + 月供压力 + 流动性差 + 维护成本 + 下跌风险。

**租房**：

- 优点：灵活 + 现金可投资 + 无维护 + 易迁城。
- 缺点：无资产 + 不安稳 + 租金波动 + 无学区。

**长期财务**：在房价温和升（2-3% / 年）的核心地段，购房 + 杠杆略优于租房 + 投资；在房价平 / 跌的远郊，租房 + 投资可能更优。

**判断**：核心地段 + 长期留 + 现金流够 → 买；远郊 / 短期留 / 现金流紧 → 租。

## 15.9　一个完整购房案例

**背景**：海归 L6 / 回阿里杭州 / 月收入 12 万 / 现金 400 万 / 一家三口 / 子女将读国际。

**决策**：

1. **买不买**：确定长期留杭州 + 配偶要求买 + 现金流够 → 买。
2. **先租 1 年**：先租未来科技城 80 平两居 1.5 万 / 月，体验 1 年。
3. **买哪里**：未来科技城（阿里通勤 + 配套成熟 + 抗跌）。
4. **买多大**：120 平三居，总价 600 万（5 万 / 平）。
5. **预算**：首付 180 万（30%），留 220 万现金（应急 + 教育 + 投资）；贷款 420 万，月供 2 万，< 收入 17%，安全。
6. **贷款**：公积金 120 万（3.1%）+ 商贷 300 万（4.2%）= 组合贷，月供 2 万。
7. **户口**：杭州购房资格松，落户 + 购房。
8. **跨境**：在美 100 万美元分 2 年汇回，合规。

**结果**：1 年后买未来科技城 120 平，月供安全，留足应急 + 教育 + 投资现金。

## 本章小结

- 默认建议：回国第一年先租，不立刻买。
- 决策树：长期留 + 配偶要求 + 现金流够 → 买；否则租。
- 区位四维度：通勤、学区、升值、配套，优先核心地段。
- 预算：首付 = 现金 - 应急 - 教育 - 其他，月供 < 收入 30%。
- 海归特殊问题：户口、贷款资格、跨境资金、美国房产、配偶产证。
- 核心地段 + 长期留 + 现金流够 → 买；远郊 / 短期 / 紧 → 租。
