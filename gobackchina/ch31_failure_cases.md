# 第 31 章　失败案例与教训集

> 市面上回国成功故事太多，失败案例被系统性低估。本章选 6 个失败案例，每个拆"为什么失败 + 关键错误 + 可避免的教训"。**知道怎么栽的比知道怎么成的更重要**。

---

## 31.1　案例一：情绪逃避 / 40 岁 / 被裁后回国 → 6 月返美

### 背景

- 40 岁，Meta E6 被裁，在美 12 年，绿卡已批，已婚二子 12/14 岁。

### 决策

- 被裁后情绪低落 + 看国内 AI 热，冲动回国。
- 拿到某 AI 创业公司 offer，现金 150 万 + 期权。
- 全家回国，子女读国际。

### 失败

- 6 个月后全家返美。
- 原因：被裁情绪未处理 + 创业公司组织混乱 + 子女 12/14 适应极难 + 配偶从未真心同意。

### 关键错误

1. **情绪驱动**：被裁后冲动，未处理情绪。
2. **家属未同步**：配偶被动同意，子女不愿。
3. **子女年龄误判**：12/14 切换极难，国际学校也难适应。
4. **创业公司未尽调**：组织混乱 + 裁员风险。
5. **方向不匹配**：被裁前做广告，回国做 AI 算法，方向不匹配。

### 教训

- **情绪驱动回国几乎必败**：先处理情绪再评估。
- **家属未同步必败**：给配偶一票否决 + 子女意愿。
- **子女 12+ 回国极难**：除非国际 + 子女愿，否则不回。
- **被裁后回国 ≠ 机会**：被裁 + 回国 = 双重负面。

## 31.2　案例二：家属反对 / 35 岁 / 配偶不愿 → 1 年返美

### 背景

- 35 岁，Google L6，在美 8 年，已婚一子 6 岁，配偶非工程岗（医疗）。

### 决策

- 本人强动机回国，配偶"为了你勉强同意"。
- 拿到字节 offer，全家回国。

### 失败

- 1 年后配偶返美带子，本人 2 年后也返美。
- 原因：配偶职业断崖（医疗资格不认）+ 全职孤立 + 文化冲击 + 想返美。

### 关键错误

1. **配偶被动同意**：非真心，落地后反悔。
2. **配偶非工程岗**：医疗回国断崖，未充分评估。
3. **配偶支持网未建**：全职 + 孤立 + 无网。
4. **本人忽视配偶情绪**：专注工作，配偶 unhappy 未及时发现。

### 教训

- **配偶被动同意 = 定时炸弹**：给一票否决权。
- **配偶非工程岗回国断崖**：医疗 / 法律 / 教育，需充分评估 + 替代。
- **配偶支持网必须建**：落地前就规划，不落地后补救。
- **家属 unhappy 是回国返美第一原因**，没有之一。

## 31.3　案例三：方向不可迁移 / 37 岁 / 美国本土业务 → 降级降薪

### 背景

- 37 岁，Amazon L6 做美国医保系统，在美 10 年，已婚无子女。

### 决策

- 回国进某大厂做通用后端。
- 薪酬降（P7 而非 P8）+ 方向边缘。

### 失败

- 2 年后离职 + 返美。
- 原因：技术归零（美国医保经验不可迁移）+ 降级降薪 + 边缘业务 + 无竞争力。

### 关键错误

1. **方向不可迁移**：美国医保系统强本地绑定，回国技术归零。
2. **降级降薪**：P7 而非 P8，薪酬降 30%。
3. **边缘业务**：通用后端非核心，无竞争力。
4. **未评估可迁移性**：第 10 章可迁移性因子忽视。

### 教训

- **方向不可迁移回国 = 技术归零**：强本地绑定业务（美国医保 / 合规 / 税务）慎回。
- **降级降薪 + 边缘业务**：回国不如留美。
- **可迁移性是关键因子**：第 10 章必须评估。

## 31.4　案例四：创业公司未尽调 / 33 岁 / AI 六小虎 → 6 月解散

### 背景

- 33 岁，Google L5 做 LLM，在美 6 年，单身。

### 决策

- 加入某 AI 创业公司（非六小虎，应用层），现金 120 万 + 期权。
- 未严格尽调。

### 失败

- 6 个月后公司解散（融资烧完 + 算力成本）。
- 期权归零 + 失业 + 简历难看。

### 关键错误

1. **未尽调**：融资 / 烧钱 / 算力 / 商业化未查。
2. **应用层高风险**：死亡率高，未评估。
3. **期权当现金**：未按第 12 章折扣估值。
4. **无备选**：all-in 一家，解散后被动。

### 教训

- **AI 创业公司必须尽调**：第 05 章 8 项清单。
- **应用层死亡率高**：除非强尽调 + 备选。
- **期权不当现金**：按 30-50% 折扣。
- **保持备选**：不 all-in 一家。

## 31.5　案例五：理想化预期 / 38 岁 / 回国后持续痛苦

### 背景

- 38 岁，Apple ICT4，在美 12 年，已婚二子 8/10 岁。

### 决策

- 回国进某大厂，预期"回国生活更好 + 子女教育不卷"。

### 失败

- 2 年后持续痛苦（未返美但 unhappy）。
- 原因：理想化国内（忽视内卷 + 节奏 + 政治）+ 子女公立内卷 + 工作强度 + 文化冲击。

### 关键错误

1. **理想化国内**：只看正面（服务 / 家庭 / 购买力），忽视负面（内卷 + 节奏 + 政治）。
2. **子女教育误判**：公立内卷未预期，国际未选。
3. **工作强度未预期**：大厂强度冲击。
4. **文化冲击未准备**：第 28 章忽视。

### 教训

- **理想化国内必痛苦**：正反都看 + 现实预期。
- **子女教育需现实**：公立内卷 + 国际贵，需权衡 + 预期。
- **工作强度需预期**：大厂卷，第 02-04 章体感。
- **文化冲击需准备**：第 28 章必须读。

## 31.6　案例六：绿卡排期放弃 / 36 岁 / 回国后想返美不能

### 背景

- 36 岁，Google L6，在美 10 年，I-140 已批 PD 排期 2025，已婚一子 6 岁。

### 决策

- 回国进字节，放弃绿卡排期。
- 2 年后想返美（家属不适应），但排期重排 10+ 年，返美极难。

### 失败

- 想返美不能，家属持续 unhappy。
- 原因：未充分评估绿卡排期放弃的不可逆性 + 无返美备选。

### 关键错误

1. **绿卡排期放弃**：近不可逆，未充分评估。
2. **无返美规划**：假设"不行再返美"，但排期放弃后不能。
3. **家属适应未预期**：配偶不适应想返美，但不能。

### 教训

- **绿卡排期放弃近不可逆**：需强理由 + 充分评估。
- **返美规划需落地**：不假设"不行返美"，需具体路径（绿卡保留 / 公民 / 外企 transfer）。
- **家属适应需预期**：配偶可能不适应，需返美备选。

## 31.7　六案例的共同失败因子

跨六案例，共同失败因子：

1. **情绪 / 逃避驱动**：案例一，被裁后冲动。
2. **家属未同步**：案例一、二、六，配偶 / 子女被动或不愿。
3. **方向不可迁移**：案例三，强本地绑定。
4. **尽调不足**：案例四，创业公司未查。
5. **理想化预期**：案例五，忽视负面。
6. **不可逆性误判**：案例六，绿卡排期放弃。
7. **可逆性未规划**：案例六，无返美备选。

## 31.8　失败案例的反向教训

从失败案例提炼的**回国前必做**：

1. **处理情绪**：如有近期负面事件，先处理再评估。
2. **家属一票否决**：配偶 + 子女（如够大）真心同意。
3. **可迁移性评估**：第 10 章，强本地绑定慎回。
4. **尽调清单**：第 05 章 8 项，创业公司必查。
5. **现实预期**：正反都看 + 第 28 章文化冲击准备。
6. **不可逆性评估**：绿卡排期 / 子女学制 / 年龄，慎重。
7. **可逆性规划**：返美路径具体落地，不假设。
8. **备选保持**：不 all-in 一家 / 一城，有备选。

## 31.9　失败率的真实估计

本书估计海归回国失败率（返美或持续 unhappy）：

- **情绪驱动**：> 90%。
- **家属未同步**：> 70%。
- **方向不可迁移**：> 60%。
- **创业公司未尽调**：> 50%。
- **理想化预期**：> 40%。
- **绿卡排期放弃 + 无备选**：> 30%。
- **整体海归**：约 25-35% 失败（返美或持续 unhappy）。

**结论**：回国失败率不低，**认真评估 + 避免常见错误可显著降低**。
