# 第 33 章　码农失业浪潮与个体应对

> 2024-2026 全球科技裁员 + AI 压缩初级 HC，"码农失业浪潮"是真实现象。本章拆浪潮本质 + 海归如何应对。

---

## 33.1　码农失业浪潮的真实数据

### 全球科技裁员

- 2022-2024：全球科技裁员超 50 万人（Meta / Amazon / Google / Microsoft / Twitter / Stripe / Salesforce 等）。
- 2024-2025：裁员持续 + 扩散到中小公司。
- 2025-2026：AI 替代加速，初级 HC 持续压缩。

### 应届生"地狱模式"

- 2024-2025 北美应届生求职极难，offer 率降 + 起薪降 + rescind 多。
- 国内应届生同样难，互联网大厂校招 HC 砍半 +。

### 中级工程师压力

- L4-L5 跳槽难 + 裁员风险 + AI 稀释价值。
- 部分中级岗被 AI + 少数高级替代。

### 高级相对稳

- L6+ 裁员率低 + 需求仍在 + AI 难替代。
- 但晋升变难 + 跳槽 HC 紧。

## 33.2　浪潮的驱动因素

1. **利率 + 估值**：2022 起加息 + 估值回调，科技降本增效。
2. **AI 替代**：大模型 + agent 替代部分初级 / 中级工作。
3. **过度扩张回调**：2020-2021 科技过度招人，2022+ 回调。
4. **地缘政治**：中美脱钩影响部分业务 + HC。
5. **结构性**：部分业务成熟 + 自动化 + 不需那么多人。

**判断**：浪潮是**周期 + 结构**叠加。周期因素（利率 / 估值）可能 2026-2027 缓解，结构因素（AI 替代）长期。

## 33.3　浪潮对海归的含义

### 对在美海归

- 如在美 L6+ 稳，回国可灵活选时机。
- 如在美 L4-L5 受威胁，回国不自动救（国内同样压缩初级）。
- 如被裁，**先处理情绪 + 评估，不冲动回国**（第 31 章案例一）。

### 对回国决策

- 浪潮使回国决策更需谨慎 + 选对方向。
- generalist / 执行型回国高危。
- AI / 芯片 / infra / 系统设计回国仍好。
- **浪潮不改变回国决策框架，但提高方向选择权重**。

### 对回国后

- 回国后仍需持续学 + 适应，不吃老本。
- 国内大厂同样有裁员 + 优化，需保持竞争力。
- 选对方向 + 公司 + 团队，降低被裁风险。

## 33.4　个体应对：五个策略

### 策略一：升级到 AI 难替代的能力

- 系统设计 + 业务判断 + 跨团队协作 + 管线。
- 0→1 创新 + 研究。
- 这些 AI 难替代，价值稳。

### 策略二：转向黄金方向

- AI 算法 / 芯片 / infra / AI 应用。
- 黄金方向需求增 + 裁员风险低。
- 如有相关背景直接转，如无 upskill。

### 策略三：用 AI 放大产出

- 用 AI 工具放大自己产出，"用 AI 的工程师" > "不用 AI 的"。
- 把 AI 当工具 + 协作伙伴，成为"AI 增强型工程师"。

### 策略四：多元化收入 + 技能

- 不要单一技能 + 单一收入。
- 副业 / 投资 / 咨询 / 开源 / 内容，多元化。
- 降低单一被裁冲击。

### 策略五：持续学习 + 适应

- AI 时代变化快，持续学新模型 / 框架 / 方向。
- 适应能力 > 单一技能。
- 关注行业变化 + 主动转。

## 33.5　被裁应对：如果被裁

### 短期（0-3 月）

1. **处理情绪**：被裁是冲击，先处理情绪（咨询 + 家人 + 朋友）。
2. **财务评估**：severance + 储蓄 + RSU vesting，能撑多久。
3. **不冲动决策**：不冲动回国 / 创业 / 大消费。
4. **保身份**：如在美国，保绿卡 / H1B grace period / 转 F2 / O1 等。

### 中期（3-12 月）

1. **升级 + upskill**：学新方向 / 框架，提升竞争力。
2. **求职**：用第 21-24 章方法，内推 + 猎头 + 多渠道。
3. **考虑选项**：留美 / 回国 / 创业 / 退休 / 转行，全面评估。
4. **副业 / 咨询**：副业 / 咨询 / 开源，保持活跃 + 收入。

### 长期（12+ 月）

1. **如找到好机会**：接受 + 重新开始。
2. **如未找到**：考虑转方向 / 创业 / 退休 / 回国。
3. **不 all-in 单一**：保持多选项。

**关键**：**被裁不冲动回国**。被裁 + 回国 = 双重负面（第 31 章案例一）。

## 33.6　回国后防被裁：保持竞争力

回国后仍需防被裁：

### 选对公司 + 团队

- 公司：财务稳 + 战略方向 + HC 稳。
- 团队：核心业务 + 资源足 + leader 好。
- 避免：边缘业务 + 裁员史 + 财务差。

### 持续高绩效

- 绩效 A/B 保岗，C/D 危险。
- 主动 + 高产出 + 业务影响，不只完成。

### 持续学习 + 适应

- 学新方向 / 框架 / 业务。
- 适应公司变化 + 主动转。

### 建不可替代性

- 做只有你能做的（稀缺技能 + 深度知识 + 关键关系）。
- 成为团队 / 项目关键人。

### 保持人脉 + 备选

- 持续建人脉 + 保持求职渠道。
- 有备选，被裁不慌。

## 33.7　码农失业浪潮的"危 + 机"

### 危

- 初级 / 中级执行型被替代。
- generalist HC 紧。
- 跳槽难 + 议价弱。
- 35+ 焦虑加剧。

### 机

- AI / 芯片 / infra 黄金方向需求增。
- 高级 + 系统设计 + 管线价值升。
- 用 AI 放大的工程师产出高。
- 创业 + 副业 + 多元化机会。
- 行业洗牌 + 新机会出现。

**判断**：浪潮对**升级 + 转黄金方向 + 用 AI**的人是机，对**吃老本 + generalist + 执行型**是危。

## 33.8　海归在浪潮中的独特位置

海归在浪潮中有独特位置：

### 优势

- 硅谷前沿经验 + 系统设计 + 大规模。
- 跨文化 + 国际化 + 出海。
- 适应 + 学习能力（出国已证明）。
- 稀缺方向（AI / 芯片 / infra）海归溢价。

### 劣势

- 硅谷经验可能过时 + 需更新。
- 国内人脉归零 + 被裁后求职难。
- 文化 / 网络折扣。
- 年龄 + 适应压力。

**判断**：海归在浪潮中**优势 > 劣势，但需主动维护优势 + 补劣势**。

## 33.9　一个完整应对案例

**背景**：海归 L6 / 35 岁 / 在美 8 年 / 做大模型训练 / 关注浪潮。

**应对**：

1. **升级**：从 IC 转 tech lead，系统设计 + 管线，AI 难替代。
2. **方向**：大模型训练是黄金方向，保持 + 深化。
3. **用 AI**：用 Claude / Cursor 放大产出，成为"AI 增强型"。
4. **多元**：主业 + 副业（技术博客 / 咨询）+ 投资，多元收入。
5. **持续学**：关注新模型 / 框架，持续更新。
6. **回国决策**：AI 时代黄金方向 + 35 岁窗口 + 绿卡已批，2025-2026 回国好时机。
7. **回国后**：选字节豆包（核心 + 资源 + 稳）+ 持续高绩效 + 建不可替代 + 保人脉备选。

**结果**：在浪潮中定位自己价值 + 主动应对，不被浪潮冲走。

## 本章小结

- 码农失业浪潮是周期 + 结构叠加，2024-2026 深化。
- 初级 / 中级执行型受冲击，高级 + 系统设计 + 黄金方向稳。
- 浪潮不改变回国框架，但提高方向选择权重。
- 五应对：升级 AI 难替代、转黄金方向、用 AI 放大、多元收入、持续学习。
- 被裁：处理情绪 + 财务评估 + 不冲动 + 保身份 + upskill + 求职 + 多选项。
- 被裁不冲动回国，被裁 + 回国 = 双重负面。
- 回国后防被裁：选对公司 + 高绩效 + 持续学 + 建不可替代 + 保备选。
- 浪潮对升级 + 转方向 + 用 AI 的人是机，对吃老本 + generalist 是危。
- 海归优势 > 劣势，但需主动维护 + 补。
