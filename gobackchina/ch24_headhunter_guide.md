# 第 24 章　猎头使用指南与反猎头话术

> 猎头是海归求职的双刃剑——用得好加速 + 计价，用不好被带偏 + 损失。本章讲如何有效使用猎头 + 识别猎头话术。

> ⚠️ **本章数字声明**：本章出现的薪酬/offer/总包/猎头费率等具体数字，均来源于 2024-2026 年互联网公开信息（脉脉、看准网、知乎、猎头行业访谈、媒体报道等）的综合估算，**并非任何公司官方标准，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

---

## 24.1　猎头的真实角色

猎头不是你的代理人，是**公司的招聘代理**：

- **猎头代表公司**：猎头由公司付佣金（通常候选人年薪酬 20-30%），代表公司利益。
- **猎头不为你谈价**：猎头希望你接受 offer（拿佣金），不会为你硬谈。
- **猎头有信息价值**：猎头知道 HC / 级别 / 薪酬水位 / 流程，信息有价值。
- **猎头有渠道价值**：猎头有公司关系，能推你进面试。
- **结论**：猎头是信息 + 渠道工具，不是你的代言人。

## 24.2　猎头的类型

### 按模式

- ** retained（保留）**：公司独家委托，高端岗常用，猎头更负责。
- **contingency（风险）**：多猎头竞争，先到先得，猎头更急。
- **内部 TA**：公司内部招聘，不是猎头但类似。

### 按专注

- **综合猎头**：Michael Page / Hays / Robert Walters / 科锐 / 猎聘，覆盖广。
- **科技专注**：任仕达 / 万宝盛华科技 / 海德思哲 / 本乡，专注科技。
- **AI / 芯片专注**：近年涌现 AI / 芯片垂直猎头，专业 + 资源深。
- **海归专注**：少数猎头专注海归，理解海外背景。

### 选择

- **高级岗（P8+ / 5-1+）**：retained + 科技 / 垂直专注。
- **中级岗（P7 / 4-1）**：contingency + 综合 / 科技。
- **海归**：优先海归专注 + 科技专注，理解你的背景。

## 24.3　如何找好猎头

### 渠道

- **LinkedIn**：猎头主动联系你，或你主动联系。
- **朋友推荐**：朋友用过的猎头，最可靠。
- **海归群**：海归群推荐猎头。
- **公司官网**：部分公司列合作猎头。

### 评估猎头质量

1. **专注领域**：是否专注你的方向（AI / 芯片 / 互联网）？
2. **资源深度**：是否与目标公司有深度合作？
3. **历史业绩**：过往成功 placement？
4. **专业度**：沟通是否专业 + 懂行？
5. **不施压**：好猎头不施压你接受 offer。
6. **信息透明**：好猎头透明分享 HC / 薪酬 / 流程。

**建议**：选 2-3 个好猎头合作，不选 10 个普通猎头。

## 24.4　与猎头合作的实操

### 初次沟通

- **明确你的背景 + 目标**：简历 + 目标公司 / 级别 / 方向 / 城市。
- **明确你的期望薪酬**：给区间，不点死。
- **明确时间线**：何时开始面试 / 何时需 offer。
- **问猎头信息**：目标公司 HC / 级别 / 薪酬水位 / 流程。

### 猎头推你

- 猎头推你到公司 HR / hiring manager。
- 确认猎头推了哪个岗位 + 何时推 + 推给谁。
- **避免多猎头推同岗位**：公司会冲突，可能拒你。**一个岗位一个猎头**。

### 面试过程

- 猎头同步面试进度 + 反馈。
- 猎头可能给面试准备建议（部分有价值，部分通用）。
- **不要全依赖猎头准备**：自己用第 38 章方法准备。

### offer 谈判

- 猎头给 initial offer。
- **猎头不会为你硬谈**（佣金驱动接受），你自己谈（第 11 章）。
- 猎头可传话 + 给信息（如"HC 还有一个，需快决"），但决策你做。
- **不要让猎头代你谈价**：猎头利益与你不对齐。

## 24.5　猎头的常见话术与应对

### 话术一："这个级别上限就是 X，不能更多"

- **真相**：上限通常可破，需 VP 审批，猎头不愿走。
- **应对**："我了解该级别通常区间是 X-Y，希望争取 Y，能否帮问审批？"

### 话术二："公司很急，需本周决定"

- **真相**：急是猎头制造紧迫感，公司通常可等 1-2 周。
- **应对**："我需要 1-2 周比较其他选项，希望公司能等。"

### 话术三："这个 offer 很好了，不要贪"

- **真相**：猎头希望你接受（佣金），不会鼓励你谈。
- **应对**："我理解，但我想争取 [具体项]，能否再谈一轮？"

### 话术四："其他候选人在等，你不决就没 了"

- **真相**：可能真有其他候选人，但也可能施压。
- **应对**："如果公司选其他候选人我理解，但我不会因施压而仓促决。"

### 话术五："你背景不一定够，先接受这个级别"

- **真相**：猎头可能压你级别以易推。
- **应对**："我背景对应更高级别，希望争取，如不行再考虑。"

### 话术六："股权按估值 X 算，总包很高"

- **真相**：估值是最近一轮，未上市期权需折扣（第 12 章）。
- **应对**："期权我按保守估值算，希望现金部分补足。"

## 24.6　猎头的红线

### 红线一：不让你直接与公司谈

- 好猎头允许你与 hiring manager 直接谈（尤其高级岗）。
- 如果猎头阻拦你与公司直接谈，警惕。

### 红线二：施压你接受

- 好猎头给信息 + 建议，不施压。
- 如果猎头反复施压你接受，换猎头。

### 红线三：信息不透明

- 好猎头透明分享 HC / 薪酬 / 流程。
- 如果猎头藏信息，警惕。

### 红线四：推你到不匹配岗位

- 好猎头推匹配岗位，不为佣金推你到不匹配。
- 如果猎头推你到明显不匹配岗位，换。

### 红线五：多猎头推同岗位

- 你必须控制一个岗位一个猎头，避免冲突。
- 如果发现多猎头推同岗位，立即协调 + 告知公司。

## 24.7　猎头 vs 内推 vs 海投

| 渠道 | 响应率 | 议价空间 | 信息价值 | 适合 |
|---|---|---|---|---|
| 内推 | 50-80% | 大（内推人帮） | 中（内推人了解） | 有内推人 |
| 猎头 | 30-50% | 中（猎头不硬谈） | 高（猎头懂市场） | 无内推人 + 高级岗 |
| 海投 | 5-15% | 小 | 低 | 低级岗 / 海归不推荐 |

**海归高级岗**：内推优先，猎头次之，海投最后。**多渠道并行**：内推 + 猎头同时，不依赖单一。

## 24.8　一个完整猎头合作案例

**背景**：海归 L6 / 目标字节 5-1 / 无直接内推人。

**找猎头**：

- LinkedIn 主动联系 3 个专注 AI 的猎头。
- 朋友推荐 1 个猎头。
- 选 2 个专业 + 不施压 + 信息透明的猎头合作。

**初联**：

- 发简历 + 明确目标（字节 5-1 豆包 / 大模型训练）+ 期望（350-500 万）+ 时间线（3 月内）。
- 猎头给信息：豆包 HC / 级别 / 薪酬水位 / 流程。

**推 + 面试**：

- 猎头推豆包 + 阿里通义（不同岗位不同猎头）。
- 面试 4-6 轮，猎头同步进度。
- 自己用第 38 章方法准备，不全依赖猎头。

**offer 谈判**：

- 猎头给 initial offer（字节 5-1，280 万）。
- 猎头说"上限就是 280"（话术一）。
- 你应对："我了解 5-1 区间 250-400，希望争取 350，能否帮问审批？"
- 猎头走审批，revised 320 万。
- 你用竞争 offer（阿里 300 万）再谈，最终 350 万。

**结果**：猎头帮推 + 给信息，但谈价你自己做，最终多拿 70 万。

## 本章小结

- 猎头代表公司不是你，是信息 + 渠道工具不是代言人。
- 选 2-3 个专注 + 专业 + 不施压 + 透明的好猎头。
- 初联明确背景 + 目标 + 期望 + 时间线，问猎头信息。
- 一个岗位一个猎头，避免冲突。
- 猎头不为你硬谈，谈价你自己做（第 11 章）。
- 识别六种话术 + 应对，不被带偏。
- 五条红线：不让直接谈、施压、藏信息、推不匹配、多猎头冲突。
- 内推 > 猎头 > 海投，多渠道并行。
