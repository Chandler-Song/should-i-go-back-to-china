# 第 21 章　网络信息收集方法论

> 回国决策的质量取决于信息质量。本章给你一套系统化的网络信息收集方法，让你在 4-8 周内建立对国内市场的准确认知。

> ⚠️ **本章数字声明**：本章作为全书信息收集方法论的核心章节，引用的薪酬/职级等示例数字均来源于 2024-2026 年互联网公开信息（Levels.fyi、脉脉、看准网、知乎、公司披露、媒体报道等），**并非任何公司官方标准，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。本章教你的正是如何自行刷新这些数字。

---

## 21.1　信息收集的三个层次

1. **宏观**：行业趋势 / 政策 / 市场周期——判断"现在是不是好时机"。
2. **中观**：公司 / 赛道 / 薪酬水位——判断"去哪类组织 / 拿什么 package"。
3. **微观**：具体团队 / leader / 岗位 / 文化——判断"这个具体 offer 好不好"。

三层信息来源不同，下文逐层给方法。

## 21.2　宏观信息源

### 行业趋势

- **36 氪 / 虎嗅 / 钛媒体**：国内科技行业新闻，每日扫。
- **晚点 LatePost**：深度报道，质量高。
- **PingWest 品玩**：科技 + 硅谷视角。
- **极客公园 / InfoQ**：技术 + 产品深度。
- **Huxiu / 钛媒体**：行业分析。
- **建议**：每日 30 分钟扫，每周 2 小时深度读。

### 政策

- **政府官网**：人社部 / 科技部 / 工信部 / 发改委，人才 / 产业 / 科技政策。
- **地方政府**：各城市人才局 / 科技局，地方人才计划。
- **专业解读**：财新 / 经济观察报 / 第一财经，政策深度解读。
- **建议**：关注目标城市人才政策 + 行业政策。

### 市场周期

- **IT 桔子**：融资 / 估值 / 创业公司数据。
- **企查查 / 天眼查**：公司工商信息 / 融资 / 法律。
- **Crunchbase**：全球融资数据。
- **建议**：关注目标公司融资 + 估值 + 烧钱速率。

## 21.3　中观信息源：公司 / 赛道 / 薪酬

### 公司信息

- **公司官网 / 招聘页**：业务 / 招聘 / 文化。
- **看准网 / 脉脉 / Boss 直聘**：公司评价 / 薪酬 / 面经。
- **知乎 / 小红书 / B 站**：员工分享 / 公司文化。
- **GitHub / 掘金 / CSDN**：技术博客 / 开源，判断技术深度。
- **建议**：对每个目标公司，看官网 + 看准 + 脉脉 + 知乎 + GitHub，多源交叉。

### 薪酬信息

- **Levels.fyi**：全球薪酬，含国内大厂。
- **看准网 / 脉脉**：国内薪酬，按公司 / 级别 / 城市。
- **OfferShow / 牛客**：offer 分享。
- **小红书 / 知乎**：海归 offer 分享。
- **建议**：多源交叉，单源不准。Levels.fyi + 脉脉 + 知乎三源对比。

### 赛道信息

- **行业报告**：艾瑞 / 易观 / IDC / Gartner 中国，行业数据。
- **券商研报**：中信 / 国信 / 中泰，芯片 / AI / 云行业深度。
- **建议**：关注目标赛道行业报告 + 券商研报。

## 21.4　微观信息源：具体团队 / leader / 岗位

### 团队 / leader

- **LinkedIn**：leader 背景 / 经历 / 跳槽史。
- **脉脉**：团队 / leader 评价（脉脉匿名评价多，需辨别）。
- **知乎 / 小红书**：团队 / leader 分享。
- **GitHub / 个人博客**：leader 技术水平。
- **建议**：对目标团队 leader，LinkedIn + 脉脉 + GitHub 三源，判断背景 + 水平 + 风格。

### 岗位

- **公司招聘页 / Boss 直聘 / 拉勾**：JD / 级别 / 薪酬范围。
- **脉脉**：岗位真实情况。
- **建议**：JD 是起点，真实情况需脉脉 + 内推人确认。

### 文化

- **看准网 / 脉脉**：文化评价（加班 / 政治 / 晋升）。
- **知乎 / 小红书**：员工真实分享。
- **建议**：文化评价匿名多 + 情绪化，需多源 + 辨别 + 与内推人确认。

## 21.5　信息收集的"三角验证"法

单源信息不可靠，本书建议**三角验证**：

```
对每个关键判断，至少三个独立来源交叉验证：
- 来源一：官方 / 数据（官网 / 报告 / 数据库）
- 来源二：员工 / 内部（脉脉 / 知乎 / 内推人）
- 来源三：外部 / 观察（新闻 / 分析 / 行业人）
三源一致 → 高置信；三源分歧 → 需深挖
```

**示例**：判断字节 5-1 薪酬：

- 来源一：Levels.fyi（数据）→ 200-300 万
- 来源二：脉脉（员工）→ 180-280 万
- 来源三：知乎海归分享（外部）→ 220-320 万
- **三源交集**：200-280 万，置信高。

## 21.6　信息收集的"时间盒"法

信息收集易陷入"无限调研"，本书建议**时间盒**：

- **总时长**：4-8 周，不超过 8 周。
- **每周**：10-15 小时，不超 20 小时。
- **阶段**：
  - 第 1-2 周：宏观（行业 / 政策 / 周期）。
  - 第 3-4 周：中观（公司 / 赛道 / 薪酬）。
  - 第 5-6 周：微观（团队 / leader / 岗位）。
  - 第 7-8 周：验证（内推人 / 猎头 / 访谈）。

**关键**：**信息收集是手段不是目的，4-8 周后必须进入行动（投简历 / 联系猎头）**，不要无限调研。

## 21.7　信息收集的"信源分级"

不同信源可靠性不同，本书分级：

### A 级（高可靠）

- 官方数据 / 报告。
- 内推人 / 朋友的一手信息。
- 自己面试 / 访谈的输出。

### B 级（中可靠）

- Levels.fyi / 看准 / 脉脉（数据多但需辨别）。
- 知乎 / 小红书 高赞分享（多但情绪化）。
- 券商研报 / 行业报告（专业但可能滞后）。

### C 级（低可靠）

- 匿名论坛 / 脉脉匿名（情绪 + 真假难辨）。
- 营销文 / 软文（猎头 / 培训机构）。
- 单一新闻 / 传言。

**原则**：A 级优先，B 级交叉，C 级仅参考。

## 21.8　信息收集的"反确认"

除了收集正面信息，**反确认**（找反面信息）同样重要：

- **目标公司**：找离职员工 / 负面评价 / 裁员新闻，了解坑。
- **目标赛道**：找赛道悲观分析 / 失败案例，避免追热。
- **目标城市**：找城市负面（气候 / 内卷 / 户籍），避免滤镜。
- **回国整体**：找回国失败案例 / 返美案例，第 31 章详述。

**反确认的目的不是劝退，是避免片面**。只看正面易冲动，正反都看才平衡。

## 21.9　信息收集的工具与效率

### RSS / 订阅

- 用 RSS（Inoreader / Feedly）订阅 36 氪 / 虎嗅 / 晚点等，集中扫。
- 节省时间 + 不漏重要。

### 微信群 / 公众号

- 关注目标公司 / 行业 / 海归公众号。
- 加海归微信群（公司群 / 城市群 / 校友群），实时信息。

### 播客 / 视频

- 播客（硅谷 101 / 科技早知道 / 创业内幕）通勤听。
- B 站 / YouTube 科技 UP 主，深度内容。

### Notion / 文档

- 用 Notion / 文档整理收集的信息，结构化。
- 按公司 / 赛道 / 城市 / 薪酬分类，便于决策。

## 21.10　信息收集的"刷新"机制

信息有时效，决策前需刷新：

- **薪酬**：季度刷新（薪酬水位变动快）。
- **政策**：半年刷新（人才 / 落户政策）。
- **公司**：月度刷新（融资 / 裁员 / 业务调整）。
- **房价**：月度刷新（房价变动）。

**建议**：决策前 1 月做一次信息刷新，避免用 6 月前的信息做今天的决策。

## 21.11　信息收集的常见坑

### 坑一：信息茧房

只看回国正面的信息（海归成功案例 / 高薪 offer），忽视负面。**正反都看**。

### 坑二：过度依赖匿名

脉脉 / 知乎匿名信息多 + 情绪化，过度依赖会偏。**A 级信源优先**。

### 坑三：信息过载

收集太多不消化，决策瘫痪。**时间盒 + 结构化整理**。

### 坑四：不刷新

用 1 年前的薪酬 / 政策做今天的决策。**决策前刷新**。

### 坑五：不验证

只看公开信息不与内推人 / 猎头 / 访谈验证。**公开信息 + 一手验证**。

## 21.12　一个完整信息收集计划

**目标**：4-8 周建立对国内 AI 赛道 + 字节 + 杭州的认知。

**第 1-2 周（宏观）**：

- 每日 30 分钟扫 36 氪 / 虎嗅 / 晚点。
- 读 AI 行业报告 + 券商研报。
- 关注杭州人才政策。

**第 3-4 周（中观）**：

- 字节：官网 + Levels.fyi + 脉脉 + 知乎 + GitHub，三角验证 5-1 薪酬。
- AI 六小虎：同上，对比。
- 杭州：房价 + 教育 + 宜居数据。

**第 5-6 周（微观）**：

- 目标团队 leader：LinkedIn + 脉脉 + GitHub。
- 岗位 JD + 脉脉真实情况。
- 文化：看准 + 知乎 + 反确认。

**第 7-8 周（验证）**：

- 联系 2-3 内推人（第 22 章）。
- 联系 1-2 猎头（第 24 章）。
- 访谈 1-2 在字节的朋友（第 23 章）。

**输出**：Notion 整理，含赛道 / 公司 / 城市 / 薪酬 / 团队 / 文化 / 风险，决策就绪。

## 本章小结

- 信息收集三层：宏观（趋势 / 政策）、中观（公司 / 薪酬）、微观（团队 / 岗位）。
- 信源分级：A 级（官方 / 内推）优先，B 级（数据 / 研报）交叉，C 级（匿名）参考。
- 三角验证：每关键判断三源交叉，三源一致高置信。
- 时间盒：4-8 周，不无限调研，之后必须行动。
- 反确认：找负面信息避免片面。
- 工具：RSS / 微信群 / 播客 / Notion 提效。
- 刷新：决策前 1 月刷新薪酬 / 政策 / 公司 / 房价。
- 五个坑：信息茧房、过度匿名、过载、不刷新、不验证。
