# 第 04 章　第三梯队与垂直龙头：拼多多 / 滴滴 / 快手 / B 站 / 携程 / 微博

> 第三梯队是"垂直领域的第一"，规模不如前两梯队，但在各自赛道有统治力。对海归，它们提供的是"小而美"或"高现金低 equity"的差异化选项。

> ⚠️ **本章数字声明**：本章出现的薪酬/总包/股权等具体数字，均来源于 2024-2026 年互联网公开信息（Levels.fyi、脉脉、看准网、知乎、公司披露、媒体报道等）的综合估算，**并非任何公司官方标准，也不代表作者一手调研**。数字仅作量级参考，变化极快，作者不为真实性负责。请用第 21 章方法自行刷新后再决策。

## 4.1　第三梯队的真实定位

第三梯队不是"差一档"，而是"另一种活法"。它们的共同特征：

1. **垂直赛道统治力**：在各自领域是第一或第二，护城河深。
2. **规模适中**：工程师 5000-20000 人，组织没那么重，个人影响力大。
3. **上市状态分化**：拼多多、快手、B 站、携程、微博已上市，滴滴上市中。
4. **海归接纳度分化**：拼多多、滴滴对海归有需求但文化冲击大；B 站、携程对海归友好但 HC 小。

**第三梯队适合"不想去大厂卷、又不想去创业公司赌"的海归**，是一个中间态选项。

## 4.2　拼多多：现金之王、最神秘、文化冲击最大的一个

### 业务与组织基因

拼多多是**下沉电商 + 农业多多 + Temu 出海**的奇迹。基因：

- **极致效率**：人均产出国内最高，工程师人均支撑 GMV 极高。
- **神秘文化**：极少对外发声，黄峥时代定的"本分"文化延续，内部信息管控严。
- **Temu 出海**：2022 年起 Temu 海外爆发，对海归 + 出海经验直接复用，是拼多多对海归最大的吸引力。
- **现金之王**：拼多多是所有互联网公司里**现金储备 / 市值比最高**的之一，财务极稳。

### 海归偏好与岗位

- **Temu 出海**：海外增长、海外工程、跨境供应链，对海归 + 出海经验极友好，是拼多多海归最集中的地方。
- **推荐 / 搜索 / 广告**：电商核心算法，对硅谷做 ranking 的人友好。
- **供应链 / 风控**：多多买菜、农业供应链，对硅谷做 supply chain 的人有需求。
- **基础架构**：拼多多技术栈现代，对硅谷 infra 背景友好。

**劝退点**：拼多多的文化冲击是所有公司里最大的——"11-11-6"（早 11 晚 11 一周 6 天）在部分团队是真实的，强制单休、年假难请、信息管控严。海归落地后 3 个月离职率不低。上海长宁地点一般。

### 薪酬与级别

拼多多职级体系不公开，海归常见落点（参考阿里）：

| 海归背景 | 拼多多职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | 对应 P6+ | 70-110 万 | 10-30 万 | 80-140 万 |
| 硅谷 L6 / 8 年 | 对应 P7+ | 110-180 万 | 30-80 万 | 140-260 万 |
| 硅谷 L7+ / 12 年+ | 对应 P8+ | 180-300 万 | 80-200 万 | 260-500 万 |

拼多多**现金占比极高、RSU 给得少**，是"现金优先"型公司。已上市，但 RSU 流动性受锁定期限制。

### 工作体感

- **优点**：现金国内顶级、人均产出高、技术挑战真、Temu 出海给海归空间、财务极稳。
- **缺点**：文化冲击最大、强度极高、信息管控、上海长宁地点一般、RSU 少。
- **适合**：做电商 / 出海、追求现金、能承受高强度、对文化冲击有准备的人。

## 4.3　滴滴：出行第一、上市中、近年在修复的一个

### 业务与组织基因

滴滴是**网约车 + 出行 + 自动驾驶**的龙头。基因：

- **出行底盘**：网约车、顺风车、代驾、青桔，国内出行第一。
- **修复期**：安全事件 + 退市后，程维时代在修复，2024 年重新上市进程中。
- **自动驾驶**：滴滴自动驾驶独立运作，对硅谷做 AV 的人有需求。

### 海归偏好与岗位

- **自动驾驶**：感知 / 规控 / 仿真，对硅谷做 AV 的人友好，但规模不如百度 Apollo。
- **调度 / 算法 / 运筹**：网约车调度、定价、匹配，对硅谷做 marketplace / 运筹的人极友好。
- **地图 / LBS**：对硅谷做 maps 的人友好。
- **国际化**：拉美 / 亚太多国运营，对海归 + 出海经验复用。

**劝退点**：滴滴整体在修复期，HC 不算宽，非 AV / 非算法岗机会少。北京中关村 / 苏州街地点好但薪酬不如第一梯队激进。

### 薪酬与级别

滴滴职级参考阿里体系，海归常见落点：

| 海归背景 | 滴滴职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | D7 / D8 | 50-80 万 | 15-30 万 | 65-110 万 |
| 硅谷 L6 / 8 年 | D8 / D9 | 80-140 万 | 30-80 万 | 110-220 万 |
| 硅谷 L7+ / 12 年+ | D10 | 140-220 万 | 60-150 万 | 200-370 万 |

滴滴上市中，RSU 流动性待定。海归议价空间在 AV / 算法方向较大。

### 工作体感

- **优点**：出行赛道第一、调度算法国内顶级、WLB 中等、北京地点好、AV 有空间。
- **缺点**：修复期 HC 紧、整体薪酬不如第一梯队、非算法岗机会少。
- **适合**：做出行 / 调度 / 运筹 / AV、重视赛道深度、可接受公司修复期的人。

## 4.4　快手：短视频第二、下沉市场第一、AI 投入认真

### 业务与组织基因

快手是**短视频 + 直播 + 电商 + 海外（Kwai）**的"下沉之王"。基因：

- **下沉基因**：在三四线城市用户基础深厚，与抖音形成差异化。
- **AI 投入认真**：可灵大模型、视频生成，2024-2025 在多模态 AI 投入显著。
- **海外 Kwai**：拉美 / 东南亚 / 中东，对海归 + 出海经验复用。

### 海归偏好与岗位

- **可灵 / 多模态 AI**：视频生成、多模态理解，对硅谷做 generative AI 的人友好，2024-2025 招人凶。
- **推荐 / 搜推**：短视频推荐，对硅谷做 ranking 的人友好。
- **海外 Kwai**：对海归 + 出海经验复用。
- **基础架构 / 视频**：视频编解码、CDN，对硅谷做 video infra 的人友好。

**劝退点**：快手整体规模和薪酬不如字节，北京 / 海口双总部，海口对海归吸引力低。

### 薪酬与级别

快手职级参考阿里体系，海归常见落点：

| 硅谷 L6 / 8 年 | K8 / K9 | 85-150 万 | 50-120 万 | 135-270 万 |
| 硅谷 L7+ / 12 年+ | K10 | 150-230 万 | 100-250 万 | 250-480 万 |

### 工作体感

- **优点**：短视频赛道第二、AI 投入认真、WLB 中等、已上市、可灵有空间。
- **缺点**：规模 / 薪酬不如字节、北京 / 海口双总部、增长承压。
- **适合**：做短视频 / 多模态 AI / 推荐的人，可接受规模小于字节。

## 4.5　B 站：Z 世代社区、文化独特、对海归友好但 HC 小

### 业务与组织基因

B 站是**Z 世代视频社区 + 游戏 + 学习**的"小破站"。基因：

- **社区文化**：弹幕、UP 主生态、二次元，文化独特且年轻。
- **多业务**：游戏（FGO、碧蓝）、学习、直播、电商，多线但都不算最大。
- **AI 投入小但精**：Index 大模型规模小但专注。

### 海归偏好与岗位

- **推荐 / 搜索**：内容推荐，对硅谷做 ranking 的人友好。
- **视频技术 / 直播**：转码、CDN、低延迟直播，对硅谷做 video 的人友好。
- **游戏技术**：自研 + 代理，对硅谷做 game 的人有需求。
- **Index 大模型**：小而精，对硅谷做 LLM 的人有少量需求。

**劝退点**：B 站规模小、HC 紧、薪酬不如大厂、上海杨浦地点一般。增长承压，盈利艰难。

### 薪酬与级别

| 海归背景 | B 站职级 | 年现金 | RSU（年化） | 总包估计 |
|---|---|---|---|---|
| 硅谷 L5 / 5 年 | 对应 P6 | 45-70 万 | 10-25 万 | 55-95 万 |
| 硅谷 L6 / 8 年 | 对应 P7 | 70-120 万 | 25-60 万 | 95-180 万 |
| 硅谷 L7+ / 12 年+ | 对应 P8 | 120-180 万 | 50-120 万 | 170-300 万 |

B 站已上市，但股价长期承压，RSU 上行有限。海归议价空间小。

### 工作体感

- **优点**：社区文化独特、年轻、WLB 较好、上海、对海归友好。
- **缺点**：规模小、HC 紧、薪酬低、增长承压、盈利难。
- **适合**：喜欢社区文化、做视频 / 推荐 / 游戏、不追求高薪的人。

## 4.6　携程：旅游第一、最稳、对海归最友好的"佛系"选项

### 业务与组织基因

携程是**OTA + 旅游 + 国际化**的龙头。基因：

- **旅游第一**：国内 OTA 绝对龙头，国际 Trip.com 增长快。
- **国际化深**：携程对海归的友好度在第三梯队里最高，英文工作环境、国际化团队多。
- **佛系文化**：WLB 好，上海凌空 SOHO 地点好。

### 海归偏好与岗位

- **国际业务 / Trip.com**：海外增长、多语言、跨境支付，对海归 + 出海经验直接复用，是携程海归最集中的地方。
- **推荐 / 搜索 / 定价**：机票 / 酒店推荐和定价算法，对硅谷做 ranking / pricing 的人友好。
- **基础架构 / 数据**：对硅谷 infra 背景友好。
- **AI / 大模型**：携程大模型专注旅游垂直，对硅谷做 domain LLM 的人有需求。

**劝退点**：携程技术深度不如大厂，薪酬中等，旅游赛道天花板有限。

### 薪酬与级别

携程职级参考阿里体系，海归常见落点：

|---|---|---|---|---|
| 硅谷 L5 / 5 年 | 对应 P6 | 50-75 万 | 15-30 万 | 65-105 万 |
| 硅谷 L6 / 8 年 | 对应 P7 | 75-130 万 | 30-80 万 | 105-210 万 |

携程已上市，财务稳，RSU 流动性好但上行有限。海归议价空间在国际化方向大。

### 工作体感

- **优点**：国际化深、对海归最友好、WLB 好、上海地点好、已上市、文化温和。
- **缺点**：技术深度一般、薪酬中等、旅游赛道天花板有限。
- **适合**：做国际化 / 出海、重视 WLB + 海归友好、不追求技术顶配的人。

## 4.7　微博：社交媒体第一、但技术吸引力下降

### 业务与组织基因

微博是**社交媒体 + 资讯 + 广告**的龙头。基因：

- **社交底盘**：国内唯一公开广场型社交，但被抖音 / 小红书分流严重。
- **新浪系**：与新浪一体，技术文化偏传统。
- **增长承压**：用户时长下降，广告收入承压。

### 海归偏好与岗位

- **推荐 / 热搜 / 广告**：对硅谷做 ranking / ads 的人友好。
- **基础架构**：对硅谷 infra 背景友好，但 HC 小。

**劝退点**：微博技术吸引力在下降，增长承压，薪酬不如大厂，海归议价空间小。**本书对海归去微博持谨慎态度**，除非有特殊原因（如家属必须在北京且要 WLB）。

### 薪酬与级别

| 硅谷 L6 / 8 年 | 对应 P7 | 65-110 万 | 20-50 万 | 85-160 万 |

### 工作体感

- **缺点**：技术吸引力下降、增长承压、薪酬低、海归议价空间小。
- **适合**：有特殊原因必须北京 + WLB 的人，否则不推荐海归首选。

## 4.9　第三梯队的隐藏价值：跳板与避风港

第三梯队常被当成"退而求其次"，但它有两个被低估的价值：

1. **跳板**：如果你拿不到第一梯队顶级 offer，第三梯队的核心岗 + 2 年经验，是重新冲第一梯队或独角兽的好跳板。尤其拼多多 Temu、滴滴 AV、快手可灵，技术含量足够能写进简历。
2. **避风港**：如果你在硅谷被裁 / 焦虑 AI 冲击，需要一个"先回国落地、再图发展"的过渡，第三梯队的 WLB 选项（携程、B 站）比直接冲字节华为更稳。

**第三梯队不是终点，可以是起点或中转**。关键是选对赛道和岗位，避免去边缘业务。

## 本章小结

- 第三梯队六家各有垂直第一：拼多多下沉电商、滴滴出行、快手下沉短视频、B 站 Z 世代、携程旅游、微博社交。
- 拼多多现金最高但文化冲击最大，携程对海归最友好，微博吸引力下降。
- 第三梯队适合"不想大厂卷、不想创业赌"的中间态，也可作跳板或避风港。
- 选型看赛道 + 海归友好度 + WLB 偏好，避免边缘业务。
