# 第 35 章　AI 时代工程师核心竞争力重塑

> AI 时代工程师的核心竞争力在重塑。本章定义新竞争力 + 海归如何定位 + 持续构建。

---

## 35.1　从"代码能力"到"系统 + 判断 + 领导"

旧竞争力（被 AI 稀释）：

- 代码量 + 速度。
- 框架 / API 熟练。
- 执行型 problem solving。

新竞争力（AI 难替代）：

- **系统设计**：分布式 / 一致性 / 高并发 / 可扩展。
- **业务判断**：产品 / 用户 / 商业 / 权衡。
- **技术领导**：架构 + 跨团队 + 影响 + 决策。
- **0→1 创新**：新方向 / 新方法 / 研究。
- **人 + 文化**：管人 / 建文化 / 培养 / 领导。
- **适应 + 学习**：持续学新 + 转方向。

**结论**：**竞争力从"写"转向"想 + 判断 + 领导 + 适应"**。

## 35.2　AI 时代工程师的五层能力模型

```
L5: 战略 + 领导（定义方向 + 建组织 + 影响行业）
L4: 架构 + 跨团队（设计大系统 + 跨团队影响 + 技术决策）
L3: 系统 + 业务（设计子系统 + 业务判断 + 端到端）
L2: 模块 + 执行（设计模块 + 独立 feature + 高质量）
L1: 代码 + 任务（写代码 + 完成任务 + 基础）
```

- **L1 被 AI 强替代**。
- **L2 被 AI 部分替代**。
- **L3-L5 AI 难替代**，价值升。
- **海归目标**：定位 L3-L5，不停留在 L1-L2。

## 35.3　海归的能力定位

### 硅谷 L4-L5（中级）

- 硅谷定位 L2-L3。
- 回国需升级到 L3（系统 + 业务），否则被 AI 稀释。
- **建议**：回国前 / 后主动升级到系统设计 + 业务判断。

### 硅谷 L6（staff）

- 硅谷定位 L3-L4。
- 回国 L3-L4，AI 难替代，价值稳。
- **建议**：保持 + 深化系统设计 + 跨团队。

### 硅谷 L7+（senior staff / principal）

- 硅谷定位 L4-L5。
- 回国 L4-L5，AI 难替代，价值升。
- **建议**：保持 + 扩展架构 + 领导 + 影响。

### 硅谷 L3（初级）

- 硅谷定位 L1。
- 回国 L1，被 AI 强替代，不推荐回国。
- **建议**：先升级到 L2-L3 再考虑回国。

## 35.4　核心竞争力的持续构建

### 系统设计

- **学**：分布式系统 / 一致性 / 高并发 / 可扩展（DDIA / Google papers / MIT 6.824）。
- **做**：设计 + 实现大系统 + 跨团队。
- **写**：技术博客 / 设计文档 / 演讲，建可见度。
- **持续**：新系统 / 新挑战 / 新规模。

### 业务判断

- **学**：产品 / 用户 / 商业 / 行业。
- **做**：参与产品 / 业务决策 + 端到端负责。
- **跨**：与产品 / 业务 / 运营深度合作。
- **持续**：新业务 / 新行业 / 新市场。

### 技术领导

- **学**：架构 / 决策 / 沟通 / 影响（staff eng 书 / Radical Candor）。
- **做**：tech lead + 跨项目 + 跨团队影响。
- **带**：带人 + 培养 + 建文化。
- **持续**：更大范围 + 更高影响。

### 0→1 创新

- **学**：研究方法 / 创新方法 / 顶会跟踪。
- **做**：新方向 / 新方法 / 新项目。
- **发**：顶会 / 顶刊 / 开源 / 专利。
- **持续**：新问题 + 新方向。

### 人 + 文化

- **学**：管理 / 领导 / 组织 / 文化（HBR / 管理 书）。
- **做**：管人 + 建团队 + 建文化。
- **带**：培养 + 晋升 + 影响。
- **持续**：更大团队 + 更深文化。

### 适应 + 学习

- **学**：学习方法 / 适应方法。
- **做**：持续学新 + 转方向。
- **跟**：跟踪行业 + 顶会 + 新技术。
- **持续**：终身。

## 35.5　海归的独特竞争力

海归在 AI 时代的独特竞争力：

### 硅谷前沿经验

- 硅谷 AI / 系统前沿 firsthand。
- 需及时回 + 持续更新，否则过时。

### 大规模系统经验

- 硅谷大规模系统（Google / Meta / Amazon 规模）。
- 国内大规模经验稀缺。

### 跨文化 + 国际化

- 跨文化协作 + 国际化 + 出海。
- AI 时代出海 + 国际化需求。

### 稀缺方向

- AI 算法 / 芯片 / infra 稀缺方向。
- 海归如有，溢价。

### 适应 + 学习能力

- 出国已证明适应 + 学习。
- AI 时代变化快有价值。

**维护**：独特竞争力需**主动维护 + 持续更新**，不吃老本。

## 35.6　竞争力的"可见度"

竞争力需可见度，不被看见 = 不存在：

### 内部可见

- 设计文档 + 演讲 + 跨团队影响。
- 高绩效 + 晋升 + 关键项目。

### 外部可见

- 技术博客 / 公众号 / 知乎 / B 站。
- 开源贡献 / 顶会论文 / 专利。
- 行业演讲 / 媒体引用。
- LinkedIn / 个人品牌。

### 可见度的价值

- 议价：被看见 = 被需要 = 议价强。
- 机会：被看见 = 机会找你。
- 抗裁：被看见 = 不可替代。
- 长期：被看见 = 长期竞争力。

**建议**：主动建可见度，不只埋头做。

## 35.7　竞争力的"复利"

竞争力是复利，早期投入长期回报：

- **系统设计**：早期学 + 做，5-10 年复利。
- **业务判断**：早期跨，5-10 年复利。
- **技术领导**：早期带，5-10 年复利。
- **可见度**：早期建，5-10 年复利。
- **人脉**：早期建，5-10 年复利。

**建议**：**早期投入复利能力，不只短期产出**。AI 时代复利能力比短期产出更值钱。

## 35.8　竞争力的"反脆弱"

AI 时代变化快，竞争力需"反脆弱"（变化中更值钱）：

### 反脆弱能力

- **适应 + 学习**：变化中更值钱。
- **系统设计**：新系统仍需设计。
- **业务判断**：新业务仍需判断。
- **技术领导**：新团队仍需领导。
- **0→1 创新**：新方向仍需创新。

### 脆弱能力

- **特定框架 / API**：过时即废。
- **特定公司流程**：换公司即废。
- **执行型代码**：AI 替代即废。
- **单一技能**：变化即废。

**建议**：**投资反脆弱能力，不投资脆能力**。

## 35.9　海归竞争力构建的"时间线"

### 回国前（6-12 月）

- 升级到系统设计 + 业务判断（如还停留在 L1-L2）。
- 学 AI / 芯片 / infra（如转方向）。
- 建可见度（博客 / 开源 / 演讲）。
- 刷人脉。

### 回国后第 1 年

- 适应 + 建内部可见 + 高绩效。
- 持续学 + 跟行业。
- 建人脉 + 同温层。

### 回国后第 2-3 年

- 深化系统设计 + 业务判断 + 技术领导。
- 扩外部可见 + 影响力。
- 晋升 + 更大范围。

### 回国后第 4-5 年

- 复利兑现 + 高议价 + 高影响。
- 反脆弱 + 持续适应。

## 35.10　一个竞争力构建案例

**背景**：海归 L6 / 33 岁 / 做大模型训练 / 回字节豆包。

**定位**：L3-L4（系统设计 + 跨团队），AI 难替代。

**构建**：

- **系统设计**：设计豆包训练 infra + 跨团队，深化。
- **业务判断**：参与模型 / 产品决策，跨。
- **技术领导**：tech lead 训练团队 + 带人。
- **0→1**：新训练方法 / 优化 / 顶会。
- **可见度**：技术博客 + 顶会 + 开源 + 演讲。
- **适应**：持续学新模型 / 框架。
- **反脆弱**：系统设计 + 业务判断 + 领导，变化中值钱。

**5 年后**：L4-L5 + 高议价 + 高影响 + 反脆弱，AI 时代竞争力强。

## 本章小结

- 竞争力从"写"转向"想 + 判断 + 领导 + 适应"。
- 五层能力模型：L1 代码（被替代）、L2 模块（部分替代）、L3-L5 系统 / 架构 / 战略（难替代）。
- 海归目标 L3-L5，不停留 L1-L2。
- 持续构建：系统设计、业务判断、技术领导、0→1、人 + 文化、适应学习。
- 海归独特：前沿经验、大规模、跨文化、稀缺方向、适应学习，需主动维护。
- 可见度：内部 + 外部，被看见 = 被需要 = 计价强。
- 复利：早期投入长期回报。
- 反脆弱：适应 / 系统 / 判断 / 领导 / 创新，变化中值钱。
- 时间线：回国前升级 + 建可见，回国后 1 年适应 + 高绩效，2-3 年深化 + 扩影响，4-5 年复利兑现。
